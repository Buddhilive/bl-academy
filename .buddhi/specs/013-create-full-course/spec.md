## 1. Course Overview & Scope

This specification defines the complete 27-lesson curriculum for **Course 03: ML for Beginners** (`track: "ml-for-beginners"`), the fourth course in Buddhilive Academy's 9-course sequential AI Engineering learning path (`00 python` → `01 ai-for-beginners` → `02 data-science-for-beginners` → `03 ml-for-beginners` → `04 generative-ai-for-beginners`).

Every lesson is grounded in the reference curriculum (`.ref/ML-For-Beginners/ML-For-Beginners-main/`), authored in the developer-friendly, pragmatic persona of `.agents/skills/my-writing-style/SKILL.md`, and replaces all proprietary Microsoft Foundry, Azure Machine Learning Designer/AutoML, Azure Responsible AI Dashboard, Azure Custom Vision, and Azure Text Analytics dependencies with open-source Python frameworks (`Scikit-Learn`, `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `imbalanced-learn`/`SMOTE`, `skl2onnx`, `ONNX Runtime`, `Flask`, `FastAPI`, `Gradio`, `TextBlob`, `NLTK VADER`, `statsmodels`, `Gymnasium`, `Fairlearn`, `SHAP`) running on **Google Colab Free Tier** (CPU) and **Google AI Studio Free Tier** (`GEMINI_API_KEY` via `google-genai` SDK).

### User Story 3 - Module 3: Multi-Class Classification, ONNX Web Inference & Unsupervised K-Means Clustering (Priority: P3)

A learner masters multi-class classification and unsupervised clustering across 6 regional-culture lessons (`Lessons 10–15`):
- **Lesson 10 (`10-introduction-to-classification-and-smote`)**: Exploring the 2,448-row, 385-column Asian and Indian Cuisines dataset (`thai`: 289, `japanese`: 320, `chinese`: 442, `indian`: 598, `korean`: 799), writing `create_ingredient_df()` to plot the top 10 ingredients per cuisine, dropping ubiquitous cross-cuisine confounders (`rice`, `garlic`, `ginger`), and balancing all 5 classes to 799 samples each (3,995 total rows) using `SMOTE` (`Synthetic Minority Over-sampling Technique`).
- **Lesson 11 (`11-multiclass-classification-and-solvers`)**: Reasoning through multiclass algorithm selection and training `LogisticRegression(multi_class='ovr', solver='liblinear')` on the balanced cuisine dataset (>80% accuracy), comparing optimization solvers (`liblinear`, `lbfgs`, `newton-cg`, `sag`, `saga`) and `ovr` vs. `multinomial` schemes, and inspecting single-recipe probability distributions (`cilantro, onion, pea, potato, tomato, vegetable_oil` $\rightarrow$ `indian`: $0.716$).
- **Lesson 12 (`12-comparing-classifiers-svc-knn-ensembles`)**: Walking the Scikit-Learn Machine Learning Estimator Map (>50 samples, labeled categories, <100K samples) and benchmarking `Linear SVC` ($78.6\%$), `KNeighborsClassifier` ($73.8\%$), RBF `SVC` ($83.2\%$), `RandomForestClassifier(n_estimators=100)` ($84.5\%$), and `AdaBoostClassifier` ($72.4\%$) across precision, recall, and $F_1$-score.
- **Lesson 13 (`13-cuisine-recommender-with-onnx`)**: Training a probability-enabled linear `SVC` on the 380-ingredient feature matrix, converting it to **ONNX** (`model.onnx`) via `skl2onnx` (`FloatTensorType([None, 380])`, `options={'nocl': True, 'zipmap': False}`), inspecting the model graph with Netron, and building both a client-side JavaScript `onnxruntime-web` refrigerator ingredient recommender and a Python `onnxruntime` + Gradio inference app in Google Colab.
- **Lesson 14 (`14-introduction-to-clustering`)**: Mastering unsupervised clustering concepts (transductive vs. inductive inference, flat Euclidean vs. non-flat non-Euclidean geometry, centroids vs. clustroids, constrained clustering, density, and the 10 Scikit-Learn clustering methods plus hierarchical/centroid/distribution/density/grid taxonomies), loading the 530-row Spotify Nigerian Songs dataset (`nigerian-songs.csv`), filtering out `'Missing'` genres and `popularity == 0` noise to focus on `afro dancehall`, `afropop`, and `nigerian pop`, and visualizing feature correlations (`energy` vs. `loudness`), bivariate KDE `jointplot` concentric rings, and `FacetGrid` scatter plots.
- **Lesson 15 (`15-k-means-clustering`)**: Inspecting 12-feature boxplots for outliers, encoding `artist_top_genre` and 5 audio features (`popularity`, `danceability`, `acousticness`, `loudness`, `energy`), running `KMeans(n_clusters=3)` with Voronoi centroid partitioning, computing the **Silhouette Score** ($0.53$), sweeping $k \in [1, 10]$ with `k-means++` to plot the **Within-Cluster Sum of Squares (WCSS) / Inertia Elbow curve**, and analyzing how unscaled feature variance impacts cluster geometry vs. `StandardScaler`.

**Why this priority**: Completes Sections 4 (`4-Classification`) and 5 (`5-Clustering`) of the reference repository, including SMOTE class balancing, 6-algorithm classifier benchmarking, ONNX model export, and K-Means clustering on Nigerian Spotify audio data.

**Independent Test**: Verify Lessons `10` through `15` build cleanly, run deterministic `<PythonRunner />` sandboxes (SMOTE synthetic nearest-neighbor interpolator & ingredient profiler, OvR logistic probability scorer, multi-classifier comparison benchmark, 380-feature ingredient recommender engine, clustering distance/geometry engine, and K-Means Lloyd's algorithm + WCSS Elbow & Silhouette calculator), and link to 6 self-contained `.ipynb` notebooks in `./notebook/ml-for-beginners/`.

**Acceptance Scenarios**:
