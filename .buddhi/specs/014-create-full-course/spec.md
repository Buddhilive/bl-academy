## 1. Course Overview & Scope

This specification defines the complete 22-lesson curriculum for **Course 04: Generative AI for Beginners** (`track: "generative-ai-for-beginners"`), the fifth course in Buddhilive Academy's 9-course sequential AI Engineering learning path (`00 python` → `01 ai-for-beginners` → `02 data-science-for-beginners` → `03 ml-for-beginners` → `04 generative-ai-for-beginners` → `05 mcp-for-beginners`).

Every lesson is grounded in its mapped reference directory (`.ref/generative-ai-for-beginners/00-course-setup` through `21-meta`), authored in the developer-friendly, pragmatic persona of `.agents/skills/my-writing-style/SKILL.md`, and replaces all proprietary Microsoft Foundry, Azure OpenAI Service, GitHub Models, Azure AI Content Safety, Azure Cognitive Search, Azure Cosmos DB, Microsoft Power Platform (Power Apps, Power Automate, Dataverse, AI Builder, Copilot Studio), PromptFlow, and Microsoft Agent Framework dependencies with open-source Python frameworks (`Hugging Face Transformers`, `Diffusers`, `PEFT`/`LoRA`, `TRL`, `bitsandbytes`, `ChromaDB`, `FAISS`, `sentence-transformers`, `scikit-learn`, `Gradio`, `tiktoken`, `mistral-common`, `onnxruntime-genai`, `OpenCV`, `Pillow`) running on **Google Colab Free Tier** (CPU & T4 GPU) and **Google AI Studio Free Tier** (`GEMINI_API_KEY` via `google-genai` SDK: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-embedding-001`, and Imagen).

### User Story 2 - Module 2: Prompt Engineering & Text/Chat Applications (Priority: P2)

A learner masters prompt engineering and builds production text and multi-turn chat applications across 4 hands-on lessons (`Lessons 05–08`):
- **Lesson 05 (`05-prompt-engineering-fundamentals`)**: Tokenization with `tiktoken` and `client.models.count_tokens()` on the Jupiter astronomy passage, understanding why base LLMs vs. RLHF instruction-tuned LLMs require prompt engineering (stochasticity, fabrications like the *"Martian War of 2076"*), decomposing prompt anatomy (**Instruction**, **Primary Content**, **Examples**, **Cues**, **Templates**, **Supporting Content**), analyzing the GitHub Copilot context assembly pipeline, and constructing multi-turn `system`/`user`/`assistant` prompts (such as the sarcastic 2020 World Series assistant and 2nd-grade Jupiter summarizer).
- **Lesson 06 (`06-creating-advanced-prompts`)**: Mastering **Zero-shot**, **Few-shot** (Shakespearean Sonnets 18, 116, 132 $\rightarrow$ sonnet about the moon), **Chain-of-Thought (CoT)** (Lisa's $7 - 1 - 4 + 1 = 3$ apples guiding Alice's $5 - 3 - 2 + 1 = 1$ apple arithmetic), **Generated Knowledge** (injecting `ACME Insurance` product catalogs and `$1000` budget constraints via template variables), **Least-to-Most** (5-step Data Science decomposition), **Self-Refine** (critiquing a vulnerable Flask `/hello` endpoint and regenerating a hardened version with `FlaskForm` validation, environment secret keys, `markupsafe.escape` XSS protection, and `@app.errorhandler(400)`), **Maieutic Prompting** (tree-of-explanations consistency pruning for a 5-step pandemic crisis plan), and sampling temperature ($T=0.1$ vs. $T=0.9$).
- **Lesson 07 (`07-building-text-generation-applications`)**: Building 3 complete Python applications powered by Google AI Studio (`gemini-2.5-flash`):
  1. **Multi-Step Recipe Generator & Shopping List Chainer** with regex input validation (`validate_number_input`, `validate_text_input`) that chains the generated recipes (`old_prompt_result`) into a second LLM prompt to produce a categorized grocery shopping list excluding ingredients already at home.

  3. **Python Study Buddy** that enforces a strict 3-part pedagogical template (`- Concept`, `- Example code`, `- Explanation`).
- **Lesson 08 (`08-building-chat-applications`)**: Distinguishing rule-based chatbots from stateful GenAI chat sessions (`client.chats.create`), applying the **4-part System Message Framework** (Audience/Capabilities/Limitations, Output Format, Examples, Behavioral Guardrails), designing accessible chat interfaces (visual, auditory, motor, cognitive), evaluating chat quality across 10 operational and ML metrics (Uptime, Latency, Precision, Recall, $F_1$ Score, Perplexity $\text{PPL} = \exp(-\frac{1}{N}\sum \log P(w_i))$, User Satisfaction, Error Rate, Retraining, Anomaly Detection), and implementing 4 multi-task chat & embedding workflows (NLP paper `tl;dr` summarization, zero-shot support ticket classification into `[Pricing, Hardware Support, Software Support]`, few-shot product naming for omni-fit shoes, and cosine similarity over word vectors `automobile`/`vehicle`/`dinosaur`/`stick` and 3 CNN/DailyMail news articles on Carlos Alberto, David Beckham, and Youssif meeting Spider-Man).

### User Story 3 - Module 3: Semantic Search, Function Calling & RAG with Vector Databases (Priority: P3)

A learner builds grounded retrieval and tool-calling systems across 3 foundational engineering lessons (`Lessons 09–11`):
- **Lesson 09 (`09-building-semantic-search-applications`)**: Contrasting keyword search vs. semantic search, unpacking the 5-stage **Video Transcript Ingestion & Enrichment Pipeline** (`scripts/`: transcript download $\rightarrow$ first-3-minute speaker extraction via LLM function calling $\rightarrow$ **3-minute segment bucketing with 20-word overlap** $\rightarrow$ 60-word segment summarization $\rightarrow$ dense vector embedding generation into `embedding_index_3m.json`), deriving **Cosine Similarity**:
  $$\text{similarity}(\mathbf{a}, \mathbf{b}) = \cos(\theta) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\|_2 \|\mathbf{b}\|_2}$$
  and building `get_videos(query, dataset, rows=5)` with threshold filtering ($\text{similarity} \ge 0.35$) that returns ranked educational video segments with timestamped YouTube deep links (`https://youtu.be/{video_id}?t={seconds}`) using **Google AI Studio `gemini-embedding-001`** and open-source **`sentence-transformers`**.
- **Lesson 10 (`10-integrating-with-function-calling`)**: Demonstrating why plain text prompting yields inconsistent key/value extraction across student profiles (`Emily Johnson`, Duke 3.7 GPA vs. `Michael Lee`, Stanford 3.8 GPA), mastering JSON Schema function declarations (`name`, `description`, `parameters`, `properties`, `required`), and implementing the 3-step Function Calling lifecycle (`User Query + Tools` $\rightarrow$ `Model Function Call` $\rightarrow$ `Live API Execution` $\rightarrow$ `Grounded LLM Synthesis`) by wiring `search_courses(role, product, level)` against a live course catalog REST API and using `google-genai` native tool calling and Pydantic `response_schema`.
- **Lesson 11 (`11-rag-and-vector-databases`)**: Unpacking the complete **Retrieval-Augmented Generation (RAG)** architecture (RAG-Sequence vs. RAG-Token, Keyword vs. Vector vs. Hybrid Search, Vector Databases vs. Traditional Databases), loading the 3 Neural Network markdown lessons (`data/perceptron.md`, `data/own_framework.md`, `data/frameworks.md`), chunking text along word boundaries with `split_text(text, max_length=400, min_length=300)` and `df.explode('chunks')`, indexing embeddings with both **`scikit-learn` `NearestNeighbors(n_neighbors=5, algorithm='ball_tree')`** and open-source **`ChromaDB`**, building the `chatbot(user_input)` grounded Q&A loop (`"what is a perceptron?"`), and quantitatively evaluating retrieval/answer fidelity across 4 benchmark queries using **Cosine Similarity**, **Euclidean Distance ($L_2$)**, **Dot Product**, and **Mean Average Precision (MAP)** (`sklearn.metrics.average_precision_score`).

**Why this priority**: Delivers the core AI Engineering data-grounding and tool-use triad (Semantic Search, Function Calling, and Vector DB RAG with MAP evaluation), replacing Azure Cognitive Search and Azure Cosmos DB with open-source `ChromaDB`, `scikit-learn` `BallTree`, `sentence-transformers`, and Google AI Studio `gemini-embedding-001`.
