## 1. Course Overview & Scope

This specification defines the complete 20-lesson curriculum for **Course 02: Data Science for Beginners** (`track: "data-science-for-beginners"`), the third course in Buddhilive Academy's 9-course sequential AI Engineering learning path (`00 python` → `01 ai-for-beginners` → `02 data-science-for-beginners` → `03 ml-for-beginners`).

Every lesson is grounded in the reference curriculum (`.ref/Data-Science-For-Beginners/`), authored in the developer-friendly, pragmatic persona of `.agents/skills/my-writing-style/SKILL.md`, and replaces all proprietary Microsoft Foundry, Azure Machine Learning, Azure Cosmos DB, Azure Stream Analytics, and Azure Cognitive Services dependencies with open-source Python frameworks (`SQLite3`, `Pandas`, `NumPy`, `SciPy`, `Matplotlib`, `Seaborn`, `PyWaffle`, `TinyDB`/`DuckDB`, `NetworkX`, `Scikit-Learn`, `FLAML`/`PyCaret`, `MLflow`, `Gradio`, `Fairlearn`, `pystac-client`) running on **Google Colab Free Tier** (CPU) and **Google AI Studio Free Tier** (`GEMINI_API_KEY` via `google-genai` SDK).

### Edge Cases & Boundary Conditions
