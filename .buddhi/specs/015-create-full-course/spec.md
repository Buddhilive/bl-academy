## 1. Course Overview & Scope

This specification defines the complete 22-lesson curriculum for **Course 05: MCP for Beginners** (`track: "mcp-for-beginners"`), the sixth course in Buddhilive Academy's 9-course sequential AI Engineering learning path (`00 python` → `01 ai-for-beginners` → `02 data-science-for-beginners` → `03 ml-for-beginners` → `04 generative-ai-for-beginners` → `05 mcp-for-beginners` → `06 ai-agents-for-beginners`).

Every lesson is grounded in its mapped reference directory inside `.ref/mcp-for-beginners/` (`00-Introduction` through `12-tooling`, including the `2026-07-28` stateless specification updates, the `CIMD vs. DCR` OAuth 2.1 security samples, the `03-GettingStarted` 15 sub-guides, `04-PracticalImplementation` pagination & SDK guides, `05-AdvancedTopics` 17 deep-dives, `08-BestPractices` reliability sidecar pattern, `09-CaseStudy` 8 real-world architectures, `10` 4-lab workshop, and `11-MCPServerHandsOnLabs` 13-lab Zava Retail PostgreSQL/vector database capstone). All tutorial prose is authored in the developer-friendly, pragmatic persona of `.agents/skills/my-writing-style/SKILL.md`.

All proprietary Microsoft Foundry, Microsoft Foundry Toolkit, Azure OpenAI Service, Azure AI Content Safety, Microsoft Prompt Shields, Microsoft Entra ID, Azure Key Vault, Azure API Management (APIM), Azure Container Apps, Azure Functions, and Azure Application Insights dependencies are replaced with open-source Python frameworks (`mcp` official Python SDK / `FastMCP`, `httpx`, `fastapi`, `pydantic`, `PyJWT`, `cryptography`, `sqlite3`, `chromadb`, `numpy`, `pytest`, `opentelemetry-api`) running on **Google Colab Free Tier** (CPU) and **Google AI Studio Free Tier** (`GEMINI_API_KEY` via `google-genai` SDK: `gemini-2.5-flash` and `gemini-embedding-001`), while preserving multi-language SDK comparative reference tables (Python, TypeScript, C#, Java Spring, Rust, Go) in the lesson prose.

### User Story 1 - Module 1: MCP Foundations, Specification 2026-07-28 & Security (Priority: P1)

A learner finishing Course 04 (`generative-ai-for-beginners/22-building-with-meta-llama-models`) transitions seamlessly into Course 05 (`mcp-for-beginners`), understands why the Model Context Protocol solves the $M \times N$ model-to-tool integration matrix by reducing custom connectors from $M \times N$ to $M + N$, explores the Host-Client-Server triad (`Tool Registry`, `Authentication`, `Request Handler`, `Response Formatter`), the Two-Layer Architecture (JSON-RPC 2.0 Data Layer + `stdio`/Streamable HTTP Transport Layer), tool and knowledge federation across servers, and sets up their **Google AI Studio Free Tier** API key (`GEMINI_API_KEY` via `google-genai`) and Python `mcp` (`FastMCP`) environment on Google Colab Free Tier (`Lesson 01`); masters the three core Server Primitives (**Resources** with `file://`, `database://`, `api://` URIs via `resources/list` & `resources/read`; **Prompts** with parameterized template substitution via `prompts/list` & `prompts/get`; **Tools** with Full JSON Schema 2020-12 and behavioral **Tool Annotations** `readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint` via `tools/list` & `tools/call`), Client Primitives (**Elicitation**, plus legacy **Sampling** and **Roots**), and JSON-RPC 2.0 wire framing and error codes (`-32700` Parse Error, `-32600` Invalid Request, `-32601` Method Not Found, `-32602` Invalid Params / Missing Resource, `-32603` Internal Error) (`Lesson 02`); analyzes the landmark **MCP Specification `2026-07-28`**—removing stateful `initialize`/`Mcp-Session-Id` sticky routing in favor of self-contained stateless requests with per-request `_meta` capabilities and `server/discover`, explicit application state handles (`basket_id`), `InputRequiredResult` multi-round-trip elicitation with base64 `requestState`, routable HTTP headers (`Mcp-Method`, `Mcp-Name`), caching metadata (`ttlMs`, `cacheScope`), W3C Trace Context (`traceparent`, `tracestate`, `baggage`), the formal **Extensions Framework** (`MCP Apps` and `Tasks` extension `tasks/get`, `tasks/update`, `tasks/cancel`), and the 12-month deprecation policy for Roots, Sampling, Logging, and Dynamic Client Registration (`Lesson 03`); and applies defense-in-depth security across the **OWASP MCP Top 10 (`MCP01`–`MCP10`)**, blocking **Token Passthrough** via strict JWT audience (`aud`) and RFC 9207 issuer (`iss`) validation, mitigating **Indirect Prompt Injection (XPIA)** and **Tool Poisoning ("Rug Pulls")** using open-source **Spotlighting & Datamarking** prompt shields and tool-schema hash pinning, and implementing **Client ID Metadata Documents (CIMD)** (where a public HTTPS URL serves as the `client_id`) alongside legacy **Dynamic Client Registration (DCR)** fallback (`Lesson 04`).

**Why this priority**: Establishes the entry bridge from Course 04 (`generative-ai-for-beginners`), updates `src/lib/curriculum.ts` (`plannedLessonCount: 22`, `runtimeBadges` including `'In-Browser Pyodide'`, and 5 structured syllabus modules), and delivers Module 1 (`Lessons 01–04`) as a standalone, build-verified MVP slice grounded in current `2026-07-28` MCP standards.

### User Story 2 - Module 2: Building MCP Servers, Clients, Gemini Hosts, Transports & Apps (Priority: P2)

A learner progresses from protocol theory to building, testing, securing, and deploying real MCP servers, clients, LLM hosts, and interactive UI apps across 6 hands-on builder lessons (`Lessons 05–10`):
- **Lesson 05 (`05-building-your-first-mcp-server-with-fastmcp`)**: Building a complete Python MCP Calculator & Engineering Reference Server using `FastMCP` (`@mcp.tool()` for `add`, `subtract`, `multiply`, `divide`, `power`, `sqrt`, `factorial`, `logarithm` with zero-division and domain guards; `@mcp.resource("calc://constants/{name}")` for mathematical constants; and `@mcp.prompt()` for step-by-step math proof workflows), while comparing equivalent server registrations across Python (`FastMCP`), TypeScript (`McpServer`), C# (`[McpServerTool]`), Java (`@Tool`), and Rust (`#[tool]`).
- **Lesson 06 (`06-building-mcp-clients-and-gemini-llm-hosts`)**: Writing both a deterministic Python MCP Client (programmatically listing and invoking server tools, resources, and prompts) and an autonomous **Gemini LLM Host Application** using Google AI Studio (`google-genai`, `gemini-2.5-flash`) that connects to the MCP server, converts MCP tool JSON Schemas into Gemini `types.Tool` declarations, lets the model decide which MCP tools to invoke for multi-step user queries, executes the calls on the MCP server, and returns the final grounded response.
- **Lesson 07 (`07-stdio-and-streamable-http-transports`)**: Mastering MCP's two standard transports:
  1. **Subprocess `stdio` Transport**: Newline-delimited JSON-RPC over `stdin`/`stdout`, process isolation, environment variable allowlisting, and keeping `stdout` strictly free of non-protocol logs by routing diagnostics to `stderr`.
  2. **Streamable HTTP Transport (`2026-07-28`)**: Single `/mcp` endpoint accepting `POST` JSON-RPC requests with required `MCP-Protocol-Version: 2026-07-28`, `Mcp-Method`, and `Mcp-Name` headers, returning either `application/json` or `text/event-stream` (SSE framing) for streamed progress notifications, and contrasting why the legacy `2024-11-05` dual-endpoint `HTTP+SSE` transport was deprecated.
- **Lesson 08 (`08-testing-and-debugging-with-mcp-inspector`)**: Implementing a comprehensive 4-layer MCP Testing & Debugging strategy:
  1. **Direct Unit Tests** on tool functions and boundary conditions (division by zero, negative square roots, malformed JSON schemas).
  2. **In-Memory Client-Server Protocol Integration Tests** with `pytest` and `pytest-asyncio`.
  3. **Protocol Conformance & Header Validation Tests** verifying `2026-07-28` `_meta`, `Mcp-Method`/`Mcp-Name` consistency, and `-32602` error codes.
  4. **Interactive Visual & CLI Debugging with MCP Inspector** (`npx @modelcontextprotocol/inspector` and a Python Inspector CLI harness that dumps raw JSON-RPC frames, latency histograms, and schema diffs).
- **Lesson 09 (`09-authentication-rbac-mcp-hosts-and-deployment`)**: Adding custom Starlette/FastAPI authentication middleware (`Basic Auth`, `Bearer JWT` validation) and **Role-Based Access Control (RBAC)** (`admin`, `analyst`, `guest` permission matrices) to a remote Streamable HTTP MCP server; configuring real-world **MCP Hosts** (`.vscode/mcp.json` for VS Code GitHub Copilot Agent Mode, `claude_desktop_config.json` for Claude Desktop, Cursor, Cline, and Windsurf) with environment secrets (`${input:api-key}`); and packaging the server into a hardened, non-root multi-stage **Docker container** with `/health` probes for cloud deployment.
- **Lesson 10 (`10-client-sampling-and-interactive-mcp-apps`)**: Understanding the legacy `2025-11-25` **`sampling/createMessage`** flow (`modelPreferences`: `costPriority`, `speedPriority`, `intelligencePriority`, human-in-the-loop approval) and migrating it to direct **Google AI Studio (`google-genai`)** calls in `2026-07-28`; then building an **Interactive MCP App (`SEP-1865`)** where a tool (`get_weather_dashboard` / `analyze_sales_chart`) links `_meta.ui.resourceUri` (`ui://weather-server/dashboard-template`) so the MCP Host renders a sandboxed interactive HTML/CSS/JS widget and communicates via `ui/initialize` and `tools/call` postMessage bridges.

**Why this priority**: Covers all 15 hands-on guides of `03-GettingStarted` (`01-first-server` through `15-mcp-apps`), giving learners complete mastery over building, connecting, testing, authenticating, configuring in IDEs, and deploying Python MCP servers and Gemini LLM hosts.

**Independent Test**: Open Lessons `05` through `10`, run all 6 `<PythonRunner />` sandboxes (FastMCP Calculator & Resource/Prompt dispatcher, Gemini LLM Host dynamic tool-discovery & function-calling loop simulator, `stdio` vs. Streamable HTTP `Mcp-Method`/`Mcp-Name` wire-frame parser & SSE multiplexer, Automated MCP Conformance & Inspector Test Runner, JWT + RBAC middleware gate & `.vscode/mcp.json` config validator, and Sampling-to-Gemini migrator + `ui://` MCP App HTML manifest compiler), and verify all 6 companion Colab notebooks (`05`–`10`).
