Training a model in a notebook is easy; keeping that model honest when it meets unseen production data is the real craft. Two mistakes trip up almost every beginner: **data leakage** (fitting scalers or imputers on the full dataset before splitting) and **aggregate-only evaluation** (trusting a single accuracy number while a whole subgroup fails silently).

In this final Phase 1 lesson, we wrap everything you learned into leak-proof Scikit-Learn `Pipeline`s, evaluate with stratified cross-validation, and run cohort-level error analysis using open-source Python.

## Learning Objectives

By the end of this lesson, you will be able to:

- Evaluate generalization reliably using `cross_val_score` and precision/recall/F1 metrics.
- Perform open-source cohort error analysis and permutation feature importance without proprietary cloud dashboards.

## Concept Walkthrough: Leak-Proof Pipelines & Cohort Debugging

### 1. Why `Pipeline` Eliminates Data Leakage

If you call `StandardScaler().fit_transform(X)` before `train_test_split`, test-set mean and variance leak into training. Putting preprocessing inside a Scikit-Learn `Pipeline` guarantees that `.fit()` learns statistics **only** from each training fold.

### 2. Beyond Accuracy: Precision, Recall & F1

On imbalanced tabular datasets, 95% accuracy can hide a broken model that never predicts the minority class. Always inspect **Precision**, **Recall**, and **$F_1$**:

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \qquad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}, \qquad F_1 = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

### 3. Cohort Error Analysis (Open-Source Alternative)

Instead of relying on proprietary cloud UIs, you can slice your test predictions by key subgroups (e.g., `region`, `age_group`) in Pandas and inspect `permutation_importance` from `sklearn.inspection` to verify which features actually drive predictions.

| Component | Purpose | Scikit-Learn Class |
| :--- | :--- | :--- |
| Mixed-type preprocessing | Route numeric vs. categorical columns cleanly | `ColumnTransformer` |
| Leak-proof workflow | Chain preprocessing + estimator | `Pipeline` |
| Robust validation | Average score across $k$ folds | `StratifiedKFold`, `cross_val_score` |
| Model debugging | Measure feature impact on test metric | `permutation_importance` |

### 2. Full `ColumnTransformer` + `Pipeline` + Error Analysis in Colab

Open the companion notebook to build a mixed-type preprocessing pipeline, run 5-fold cross-validation, and inspect `permutation_importance` and cohort error rates:

<ColabButton notebook="08-tabular-evaluation-and-pipelines.ipynb" />

```python
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.pipeline import Pipeline
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

df = pd.DataFrame({
    "age": [25, 42, None, 35, 51, 29, 44, 38],
    "income": [45000, 82000, 61000, None, 95000, 52000, 78000, 67000],
    "region": ["North", "South", "North", "East", "South", "East", "North", "South"],
    "converted": [0, 1, 0, 1, 1, 0, 1, 0],
})

X, y = df.drop(columns=["converted"]), df["converted"]
pre = ColumnTransformer([
    ("num", Pipeline([("imp", SimpleImputer(strategy="median")), ("sc", StandardScaler())]), ["age", "income"]),
    ("cat", OneHotEncoder(handle_unknown="ignore"), ["region"]),
])
pipe = Pipeline([("pre", pre), ("clf", RandomForestClassifier(n_estimators=50, random_state=42))])
print("CV scores:", cross_val_score(pipe, X, y, cv=3))
```
