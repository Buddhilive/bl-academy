Binary classification asks "yes or no", while real-world problems usually ask "which category out of many?". In `.ref/ML-For-Beginners`, this shows up as predicting a national cuisine from a vector of ingredients—Indian, Thai, Chinese, Japanese, or Korean.

When I compare classifiers on a new tabular dataset, I rarely guess which algorithm will win upfront. Instead, I balance class distributions first, then benchmark a small family of classifiers—linear, distance-based, margin-based, and tree-based—on the same split.

## Learning Objectives

By the end of this lesson, you will be able to:

- Prepare imbalanced multi-class datasets using stratified splits and oversampling (`SMOTE` or `class_weight="balanced"`).

- Read a multi-class **confusion matrix** and **classification report** (precision, recall, macro F1).

## Concept Walkthrough: Four Core Classifier Families

### 1. K-Nearest Neighbors (KNN)
KNN stores training points and classifies a new sample by majority vote among its $k$ closest neighbors in feature space (usually Euclidean distance):

$$d(\mathbf{x}, \mathbf{z}) = \sqrt{\sum_{j=1}^{m}(x_j - z_j)^2}$$

Because distance depends on feature scale, **always** scale numeric features (`StandardScaler`) before fitting KNN.

### 2. Support Vector Machines (SVC)
An SVM finds the separating hyperplane with the widest **margin** between classes. With an RBF kernel, it can carve non-linear boundaries without manually engineering polynomial terms.

### 3. Decision Trees & Random Forests
A Decision Tree splits features recursively to minimize node impurity—commonly **Gini impurity**:

$$G = 1 - \sum_{c=1}^{C} p_c^2$$

A single deep tree memorizes noise easily. A **Random Forest** averages predictions across many trees trained on bootstrap samples and random feature subsets, cutting variance dramatically.

| Classifier | Needs Feature Scaling? | Handles Non-Linear Boundaries? | Key Hyperparameter |
| :--- | :---: | :---: | :--- |
| `LogisticRegression` | Yes | Linear (unless features expanded) | `C` (regularization) |
| `KNeighborsClassifier` | Yes | Yes | `n_neighbors` ($k$) |
| `SVC(kernel="rbf")` | Yes | Yes | `C`, `gamma` |
| `RandomForestClassifier` | No | Yes | `n_estimators`, `max_depth` |

### 2. Multi-Class Classifier Benchmark in Google Colab

Open the Colab notebook to benchmark `LogisticRegression`, `KNeighborsClassifier`, `SVC`, and `RandomForestClassifier` with `classification_report` and confusion matrices:

<ColabButton notebook="05-classification-methods.ipynb" />

```python
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC
from sklearn.metrics import classification_report

X, y = load_wine(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)

for name, clf in [
    ("SVC (RBF)", make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0))),
    ("RandomForest", RandomForestClassifier(n_estimators=100, random_state=42)),
]:
    clf.fit(X_train, y_train)
    print(f"=== {name} ===")
    print(classification_report(y_test, clf.predict(X_test)))
```
