Standard tabular ML assumes rows are independent—shuffle them and nothing breaks. **Time series** breaks that assumption: today's electrical load or daily traffic depends directly on yesterday's values, weekly cycles, and long-term trends.

If you take one rule away from `.ref/ML-For-Beginners` on time series, make it this: **never randomly shuffle a time series into train and test sets.** Always split chronologically so the past predicts the future.

## Learning Objectives

By the end of this lesson, you will be able to:

- Split time-indexed data chronologically and explain why random splitting causes temporal data leakage.
- Explain **stationarity**, **differencing**, and the $(p, d, q)$ parameters of an **ARIMA** model.
- Reframe a time series into lagged tabular windows for **Support Vector Regression (SVR)** and evaluate with **MAPE**.

## Concept Walkthrough: Sequential Modeling with ARIMA & SVR

### 1. Stationarity and ARIMA $(p, d, q)$

A **stationary** series has a constant mean and variance over time. Real-world series (like hourly power load) drift and cycle, so **differencing** subtracts the prior value to stabilize the mean:

$$\Delta y_t = y_t - y_{t-1}$$

An **ARIMA$(p, d, q)$** model combines three pieces:
- **AR ($p$)**: Autoregressive lags—predicts $y_t$ from its last $p$ values.
- **I ($d$)**: Integrated—number of differencing steps applied to achieve stationarity.
- **MA ($q$)**: Moving Average—uses the last $q$ forecast errors.

### 2. Lagged Windows + Support Vector Regression (SVR)

You can also convert a 1D time series into supervised tabular rows by stacking $L$ past lags as features $[y_{t-L}, \dots, y_{t-1}] \to y_t$, then fitting `SVR(kernel="rbf")` from Scikit-Learn.

To compare forecast accuracy across different scales, we track **Mean Absolute Percentage Error (MAPE)**:

$$\text{MAPE} = \frac{100\%}{n}\sum_{t=1}^{n}\left|\frac{y_t - \hat{y}_t}{y_t}\right|$$

| Approach | Library | Best For | Key Requirement |
| :--- | :--- | :--- | :--- |
| ARIMA / SARIMAX | `statsmodels` | Univariate series with clear trend/seasonality | Stationary after $d$ differences |
| Lagged SVR | `scikit-learn` | Non-linear patterns & multi-step lagged windows | Feature scaling (`MinMaxScaler` / `StandardScaler`) |

### 2. ARIMA & SVR Forecasting in Google Colab

Open the Colab notebook to fit a `statsmodels` SARIMAX/ARIMA model and a Scikit-Learn `SVR` forecaster on chronological splits:

<ColabButton notebook="07-time-series-forecasting.ipynb" />

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.statespace.sarimax import SARIMAX

t = np.arange(120)
load = 100 + 0.4 * t + 12 * np.sin(2 * np.pi * t / 12) + np.random.default_rng(42).normal(0, 2, 120)
train, test = load[:96], load[96:]

model = SARIMAX(train, order=(1, 1, 1), seasonal_order=(1, 1, 1, 12)).fit(disp=False)
forecast = model.forecast(steps=len(test))
mape = np.mean(np.abs((test - forecast) / test)) * 100
print(f"SARIMAX Test MAPE: {mape:.2f}%")
```
