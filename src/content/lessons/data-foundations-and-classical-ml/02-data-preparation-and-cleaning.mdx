Real-world datasets rarely arrive as tidy CSV files. Most of the time, you are pulling records out of a relational database with SQL, flattening nested JSON payloads from an API, and then scrubbing away missing values, duplicate rows, and inconsistent types.

By the way, if you skip this cleanup step and jump straight into training a model, your model simply learns the noise. Cleaning data is not glamorous, yet it is the single highest-leverage habit in applied machine learning.

## Learning Objectives

By the end of this lesson, you will be able to:

- Query a relational database (`sqlite3`) directly into a Pandas `DataFrame` using `pd.read_sql_query()`.
- Flatten nested JSON records into tabular columns using `json` and `pd.json_normalize()`.
- Diagnose and resolve missing values (`isna()`, `dropna()`, `fillna()`), duplicates (`duplicated()`, `drop_duplicates()`), and type coercion errors.

## Concept Walkthrough: Ingesting and Scrubbing Data

Data sources fall into two broad camps covered in `.ref/Data-Science-For-Beginners`:

1. **Relational Sources (SQL)**: Structured tables with primary/foreign keys, queried via `SELECT ... JOIN ... WHERE`. Python's built-in `sqlite3` module lets you run full SQL queries locally or in Colab with zero server setup.
2. **Non-Relational Sources (JSON / Document)**: Semi-structured key-value trees where fields can be nested or missing on individual records.

### Missingness & Imputation Strategy

Before dropping or filling `NaN` values, check the fraction of missing values per column:

$$\text{Missing Rate}_j = \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}(x_{ij} \text{ is NaN})$$

| Problem | Detection | Practical Fix |
| :--- | :--- | :--- |
| Missing numeric values | `df.isna().sum()` | `df[col].fillna(df[col].median())` (robust to outliers) |
| Missing categorical values | `df[col].isna().sum()` | `df[col].fillna("Unknown")` or mode |
| Duplicate records | `df.duplicated().sum()` | `df.drop_duplicates(subset=[...], keep="first")` |
| String-encoded numbers | `df.dtypes` shows `object` | `pd.to_numeric(df[col], errors="coerce")` |
| Inconsistent whitespace/case | `df[col].unique()` | `df[col].str.strip().str.lower()` |

### 2. Full Pandas Data Preparation in Google Colab

Open the companion notebook to combine `sqlite3`, `pd.json_normalize()`, missing-value imputation, and duplicate removal on a messy dataset:

<ColabButton notebook="02-data-preparation-and-cleaning.ipynb" />

```python
import pandas as pd
import numpy as np

raw = pd.DataFrame({
    "order_id": [101, 102, 102, 103, 104],
    "city": [" Colombo ", "kandy", "kandy", None, "Galle"],
    "amount": ["25.50", "40.00", "40.00", "invalid", "18.75"],
})

clean = (
    raw.drop_duplicates(subset=["order_id"])
       .assign(
           city=lambda d: d["city"].fillna("unknown").str.strip().str.title(),
           amount=lambda d: pd.to_numeric(d["amount"], errors="coerce"),
       )
)
clean["amount"] = clean["amount"].fillna(clean["amount"].median())
print(clean)
```
