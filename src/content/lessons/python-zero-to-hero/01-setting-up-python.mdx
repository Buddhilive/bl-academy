## Setting Up Python

Programming in Python requires two core components on your machine: an up-to-date Python 3 interpreter to parse and execute code instructions, and an environment to write, edit, and experiment with your programs. In this chapter, you will establish a clean, standard programming environment by installing official Python 3 and learning how to navigate Python's built-in development environment, **IDLE** (*Integrated Development and Learning Environment*).

---

## 1.1 A Note on Python Versions

Before downloading any installer, it is vital to distinguish between operating system utilities and your dedicated learning environment.

### System Python vs. Dedicated Python 3

Many operating systems, particularly macOS and various Linux distributions, ship with a pre-installed version of Python known as **System Python**. Operating system internal utilities often rely on this runtime to perform housekeeping tasks. 

However, system Python has two major drawbacks for learners:
1. **Outdated releases:** System Python is frequently pinned to legacy or older builds that lack modern language enhancements.
2. **Incomplete environments:** System installations often omit developer tools such as IDLE or package management utilities.

Installing the latest Python 3 release from the official [Python Software Foundation](https://www.python.org/downloads/) installs an isolated, modern runtime alongside your system Python without interfering with underlying OS tasks.

### Third-Party Distributions Warning

Third-party package managers (such as Homebrew on macOS) and all-in-one data science bundles (such as Anaconda) are popular in specialized production workflows. However, beginners following standard Python tutorials are strongly advised against using them initially. 

Third-party distributions often alter default executable search paths, relocate the standard library, or package non-standard IDEs. Standard introductory materials and IDLE behaviors are verified exclusively against canonical packages distributed directly via `python.org`.

## 1.2 Windows Setup Tutorial

Modern Windows installations do not bundle Python by default. Setting up Python on Windows involves downloading the executable installer and ensuring the interpreter is discoverable by your system.

### Step 1: Download the Windows Installer
1. In your browser, navigate to the official [Python for Windows Download Page](https://www.python.org/downloads/windows/).
2. Select a currently supported **Python 3 release**.
3. Scroll down to the files section and choose the **Windows x86-64 executable installer** for modern 64-bit machines, or the 32-bit installer if your processor uses 32-bit architecture.

A 64-bit architecture provides access to an address space of $2^{64}$ bytes ($\approx 1.84 \times 10^{19}$ bytes), removing the restrictive 4-gigabyte ($2^{32} \text{ bytes} = 4 \text{ GB}$) memory ceiling inherent to 32-bit runtimes.

### Step 2: Run the Installer (Crucial Step!)
1. Locate the downloaded `.exe` file in your Downloads folder and double-click to launch it.
2. **CRITICAL:** At the bottom of the initial installer screen, check the box labeled **"Add Python 3.x to PATH"**. Enabling this setting adds the Python binary directory to Windows environment variables, allowing command-line tools to discover `python` from any terminal prompt.
3. Click **Install Now** and wait for the wizard to complete.

### Step 3: Launch IDLE
1. Open the Windows **Start Menu**.
2. Locate the **Python 3.x** folder in the application list.
3. Click **IDLE (Python 3.x)** to open the interactive shell window.

## 1.3 macOS Setup Tutorial

macOS machines historically shipped with a legacy Python 2 installation deprecated by Apple. For modern development, you must install the official Python 3 package.

### Step 1: Download the macOS Installer
1. Navigate to the official [Python for macOS Download Page](https://www.python.org/downloads/macos/).
2. Select the **Latest Python 3 Release**.
3. Download the **macOS 64-bit universal2 installer** package (`.pkg`).

### Step 2: Run the Installer Package
1. Double-click the downloaded `.pkg` file.
2. Follow the setup wizard prompts, review the license agreement, and click **Agree**.
3. Accept the default target disk location and complete the installation.

### Step 3: Launch IDLE on macOS
You can launch IDLE using either of two methods:
- **Via Finder:** Open Finder $\rightarrow$ navigate to **Applications** $\rightarrow$ open the **Python 3.x** folder $\rightarrow$ double-click **IDLE**.
- **Via Spotlight:** Press `Cmd + Spacebar`, type `idle`, and press `Return`.

## 1.4 Ubuntu Linux Setup Tutorial

Ubuntu Linux comes with Python 3 pre-installed, but you should verify that it is a supported release.

### Step 1: Check Current Version & Distribution
Open your terminal emulator and verify your installed Python 3 version:

```bash
python3 --version
```

If `python3 --version` reports an unsupported release, check your Ubuntu version:

```bash
lsb_release -a
```

### Step 2: Install Python 3 & IDLE via APT
The installation procedure depends on your Ubuntu release:

- **For recent supported Ubuntu releases:** Python 3 is available in the official repositories:
  ```bash
  sudo apt-get update
  sudo apt-get install python3 idle-python3
  ```

### Step 3: Launch IDLE from the Terminal
In your terminal, execute:

```bash
idle3
```

Confirm that the IDLE header displays a currently supported Python 3 release.

## 1.5 Understanding IDLE & The Interactive Shell

When IDLE launches, it presents the **Python Shell** (interactive window). The shell acts as a direct conversation interface with the Python interpreter:

- **Header Information:** The top banner displays the interpreter version, compiler details, and host operating system architecture.
- **The Prompt (`>>>`):** The three right-angle brackets `>>>` represent the primary interactive prompt. It signals that Python is active, idling, and awaiting your command.

When you type an expression and hit `Enter`, Python reads your statement, evaluates its result, prints the output, and loops back for another input. This cycle is formally known as a **REPL** (*Read-Eval-Print Loop*).
