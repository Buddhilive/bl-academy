Despite its name, **Logistic Regression** is a linear *classification* algorithm. Instead of predicting a continuous dollar price, it predicts the probability of a binary category—such as whether a pumpkin is `ORANGE` ($0$) or `WHITE` ("Ghost", $1$). Even better, unlike linear regression, logistic regression does not require input features to correlate linearly with each other.

---

## Encoding Mixed Categorical Features with `ColumnTransformer`

Our pumpkin dataset contains two distinct kinds of categorical text columns, so we pair two Scikit-Learn encoders inside a single `ColumnTransformer`:

1. **`OrdinalEncoder`**: Used when categories follow a natural order—like `Item Size` (`['sml', 'med', 'med-lge', 'lge', 'xlge', 'jbo', 'exjbo']` mapped to `0..6`).
2. **`OneHotEncoder(sparse_output=False)`**: Used for unordered nominal columns (`City Name`, `Package`, `Variety`, `Origin`).
3. **`LabelEncoder`**: Converts the target `Color` column into `0` and `1`.

## The Sigmoid Function, Confusion Matrix & ROC-AUC

Logistic regression passes a linear score $z$ through the **Sigmoid (Logistic) Function** to squash outputs into $(0, 1)$:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

If $\sigma(z) \ge 0.5$, the model predicts class `1`; otherwise `0`. To evaluate performance beyond raw accuracy, we inspect a **$2 \times 2$ Confusion Matrix** (where rows are actual labels and columns are predicted labels):

| Metric | Formula | Pumpkin Model Benchmark |
| :--- | :--- | :--- |
| **Precision** | $\frac{\text{TP}}{\text{TP} + \text{FP}}$ | $22 / (22 + 4) = 0.85$ |
| **Recall** | $\frac{\text{TP}}{\text{TP} + \text{FN}}$ | $22 / (22 + 11) = 0.67$ |
| **$F_1$-Score** | $\frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$ | $0.75$ |
| **Accuracy** | $\frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}$ | $(22 + 162) / 199 = 0.92$ |

Alongside those four core metrics, Scikit-Learn's `classification_report()` prints **Support** (the number of true instances per class), **Macro Avg** (the unweighted mean across classes, treating minority and majority classes equally), and **Weighted Avg** (the mean weighted by each class's support). Plotting the True Positive Rate against the False Positive Rate across every probability threshold yields the **ROC Curve**, summarized by the Area Under the Curve (`roc_auc_score` $\approx 0.975$ on the pumpkin test fold). Visually, you want that curve to shoot steeply toward the top-left corner—far above the diagonal random-guess baseline.
