## Normalizing Cities & Extracting the 8 High-Signal Tags

First, we drop `lat`/`lng`, replace `Hotel_Address` with its canonical city-country (`Amsterdam, Netherlands`: 105 hotels; `Barcelona, Spain`: 211; `London, United Kingdom`: 400; `Milan, Italy`: 162; `Paris, France`: 458; `Vienna, Austria`: 158), and recompute `Total_Number_of_Reviews` and `Average_Score` directly from the dataset rows.

Next, the raw `Tags` column packs variable-length comma-separated lists across 2,428 unique phrases (`Submitted from a mobile device`, `Stayed 1 night`, `Double Room`). Stripping brackets and filtering out device, stay-length, and room-type noise leaves **8 high-signal binary indicators**:

## Cached Stop-Word Removal, VADER & Gemini Sarcasm Audit

Caching `cache = set(stopwords.words("english"))` shrinks the longest negative review from `395` words to `195` sentiment-bearing words in just `3.3` seconds across 515K rows. We then compute compound polarity $[-1, 1]$ with **NLTK VADER** (`SentimentIntensityAnalyzer`), returning `0` for `"No Negative"` and `"No Positive"`.

Remember VADER's blind spot: a sarcastic review like *"Of course I LOVED sleeping in a room with no heating"* uses capitalized `"LOVED"`, so VADER scores it positive! In our Colab notebook, we pair VADER with **Google AI Studio Free Tier** (`gemini-2.5-flash` via `GEMINI_API_KEY`) to flag sarcasm accurately.

## Try It Yourself: Tag Extractor, Stop-Word Filter & VADER Scorer

Let's run the city normalizer, 8-tag binary encoder, cached stop-word stripper, and VADER-style compound sentiment scorer in pure Python.

**Hotel Tag Encoder & Sentiment Pipeline**

```python
STOPWORDS = {"the", "a", "an", "in", "with", "and", "was", "were", "no", "of", "to"}
VALENCE = {"noisy": -1.6, "broken": -1.8, "heating": 0.0, "loved": 3.2, "great": 2.5}

raw_addr = "123 Westminster Bridge Rd, London, United Kingdom"
city = "London, United Kingdom" if "United Kingdom" in raw_addr else "Other"

raw_tags = "[' Leisure trip ', ' Couple ', ' Double Room ', ' Stayed 2 nights ']"
leisure = 1 if "Leisure trip" in raw_tags else 0
couple = 1 if "Couple" in raw_tags else 0
pet = 1 if "With a pet" in raw_tags else 0
print(f"City: {city} | Tags -> Leisure: {leisure}, Couple: {couple}, Pet: {pet}")

neg_review = "The room was noisy with broken heating"
filtered = [w.lower() for w in neg_review.split() if w.lower() not in STOPWORDS]
print(f"Filtered Negative Words: {filtered}")

def compound_score(text):
    if text in ("No Negative", "No Positive"):
        return 0.0
    total = sum(VALENCE.get(w.lower(), 0.0) for w in text.split())
    return total / ((total * total + 15.0) ** 0.5)

neg_score = compound_score(" ".join(filtered))
pos_score = compound_score("No Positive")
print(f"VADER-Style Compound -> Neg: {neg_score:.2f}, Pos: {pos_score:.2f} (No Positive sentinel)")

sarcastic = "Of course I LOVED sleeping in a room with no heating"
print(f"Sarcasm Alert ('{sarcastic}'): Lexicon={compound_score(sarcastic):+.2f} vs True=Negative")
```

**Expected Output:**

```text
City: London, United Kingdom | Tags -> Leisure: 1, Couple: 1, Pet: 0
Filtered Negative Words: ['room', 'noisy', 'broken', 'heating']
VADER-Style Compound -> Neg: -0.66, Pos: 0.00 (No Positive sentinel)
Sarcasm Alert ('Of course I LOVED sleeping in a room with no heating'): Lexicon=+0.64 vs True=Negative
```
