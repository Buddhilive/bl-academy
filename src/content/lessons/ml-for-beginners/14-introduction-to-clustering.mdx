Up to now, every model we trained had a labeled target column $y$. **Clustering** flips that script: it is **unsupervised learning**, meaning your dataset has no predefined output labels, and the algorithm discovers natural groupings on its own—like sorting a mixed laundry pile by color and owner. In this lesson, we explore clustering theory and visualize **530 Nigerian Spotify songs** (`nigerian-songs.csv`) to see how genres overlap.

## Clustering Vocabulary, Geometry & Scikit-Learn Methods

Before picking a clustering algorithm, you need four foundational concepts:

- **Transductive vs. Inductive**: *Inductive* clustering learns general rules from training data to classify future points; *transductive* clustering groups the observed points directly without assuming labels for unseen data.
- **Flat vs. Non-Flat Geometry**: *Flat* geometry measures straight-line **Euclidean** distance between points; *non-flat* geometry measures distances along curved manifolds.
- **Centroids vs. Clustroids**: A *centroid* is the arithmetic mean of a cluster (may not be an actual data point); a *clustroid* is the real data point closest to all other points in the cluster.
- **Constrained & Density Clustering**: Semi-supervised rules (`must-link` / `cannot-link`) or density thresholds (`DBSCAN`, `OPTICS`) handle noisy, uneven shapes.

| Scikit-Learn Method | Clustering Family | Geometry & Best Use Case |
| :--- | :--- | :--- |
| **K-Means** | Centroid | General-purpose, flat Euclidean, inductive |
| **DBSCAN / OPTICS** | Density-based | Non-flat geometry, uneven/noisy clusters, transductive |
| **Agglomerative / Ward** | Hierarchical | Many constrained clusters, supports non-Euclidean distances |
| **Gaussian Mixtures** | Distribution-based | Flat geometry, probabilistic soft cluster membership |
| **Affinity Propagation / Mean-Shift** | Exemplar / Mode-seeking | Many uneven clusters when $k$ is unknown |

## Try It Yourself: Nigerian Songs Filter & Correlation Profiler

Let's filter out `'Missing'` genres and zero-popularity tracks in pure Python, count the top three Nigerian genres, and compute the exact Pearson correlation between `energy` and `loudness`.

**Nigerian Spotify Genre Filter & Correlation**

```python
import math

songs = [
    {"genre": "afropop",        "pop": 48, "energy": 0.42, "loudness": -6.70},
    {"genre": "afropop",        "pop": 30, "energy": 0.68, "loudness": -5.64},
    {"genre": "afro dancehall", "pop": 52, "energy": 0.85, "loudness": -3.20},
    {"genre": "afro dancehall", "pop": 41, "energy": 0.79, "loudness": -4.10},
    {"genre": "nigerian pop",   "pop": 14, "energy": 0.61, "loudness": -4.96},
    {"genre": "nigerian pop",   "pop": 64, "energy": 0.91, "loudness": -2.50},
    {"genre": "Missing",        "pop": 22, "energy": 0.50, "loudness": -6.00},
    {"genre": "afropop",        "pop": 0,  "energy": 0.72, "loudness": -5.10},
]

top3 = {"afropop", "afro dancehall", "nigerian pop"}
clean = [s for s in songs if s["genre"] in top3 and s["pop"] > 0]
print(f"Filtered tracks: {len(clean)} of {len(songs)}")

counts = {g: sum(1 for s in clean if s["genre"] == g) for g in ["afropop", "afro dancehall", "nigerian pop"]}
print(f"Top genres -> afropop: {counts['afropop']}, afro dancehall: {counts['afro dancehall']}, nigerian pop: {counts['nigerian pop']}")

es = [s["energy"] for s in clean]
ls = [s["loudness"] for s in clean]
me, ml = sum(es) / len(es), sum(ls) / len(ls)
cov = sum((e - me) * (l - ml) for e, l in zip(es, ls))
std_e = math.sqrt(sum((e - me) ** 2 for e in es))
std_l = math.sqrt(sum((l - ml) ** 2 for l in ls))
print(f"Pearson corr(energy, loudness): {cov / (std_e * std_l):.3f}")
```

**Expected Output:**

```text
Filtered tracks: 6 of 8
Top genres -> afropop: 2, afro dancehall: 2, nigerian pop: 2
Pearson corr(energy, loudness): 0.951
```
