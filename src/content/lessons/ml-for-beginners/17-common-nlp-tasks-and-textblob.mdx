## The Nine Core Classical NLP Tasks

Think of classical NLP like preparing vegetables before cooking: first you chop a sentence into bite-sized words (**tokenization**), label what role each word plays (**POS tagging**), group neighboring words (**N-grams** and **noun phrases**), and reduce word variations like *"running"* and *"ran"* back to their root (**lemmatization**). Here is how all nine tasks fit together:

| NLP Task | What It Does | Concrete Example |
| :--- | :--- | :--- |
| **1. Tokenization** | Splits raw text into words/tokens while handling punctuation | `"Pride, and Prejudice!"` $\rightarrow$ `['Pride', 'and', 'Prejudice']` |
| **2. Word Embeddings** | Maps words into dense numeric vectors where similar meanings cluster | `'toy'` clusters near `'lego'` and `'console'` |
| **3. Parsing & POS Tagging** | Tags words as nouns, verbs, adjectives and links phrase structure | `fox` (noun), `jumped` (verb) |
| **4. Word & Phrase Frequencies** | Counts term occurrences (case-sensitive or insensitive) | In Kipling's *The Winners*: `'the'` $= 6$, `'a friend'` $= 2$ |
| **5. N-Grams** | Sliding window of $n$ consecutive words ($n=1$ unigram, $2$ bigram, $3$ trigram) | `'the quick red'`, `'quick red fox'` |
| **6. Noun Phrase Extraction** | Extracts subject/object phrases (`ConllExtractor` trained on 211,727 WSJ tokens) | `'quick red fox'`, `'lazy brown dog'` |
| **7. Sentiment Analysis** | Scores polarity $[-1.0, 1.0]$ and subjectivity $[0.0, 1.0]$ | `"I love this"` $\rightarrow$ positive polarity |
| **8. Inflection** | Converts words between singular and plural forms | `'lovely cat'` $\rightarrow$ `'lovely cats'` |
| **9. Lemmatization & WordNet** | Reduces inflections to root lemma using lexical databases like WordNet | *flew, flies, flying* $\rightarrow$ `'fly'` |

## Upgrading Marvin with Polarity & Noun Phrases

Using `TextBlob` with `ConllExtractor` (a chunk parser trained on 211,727 Wall Street Journal tokens from the CoNLL-2000 corpus), our upgraded Marvin checks four polarity bands (`<= -0.5`, `<= 0`, `<= 0.5`, `<= 1.0`), extracts any detected `noun_phrases`, pluralizes the noun phrase, and asks: *"Can you tell me more about lovely cats?"* That single addition makes the bot dramatically more believable than random replies, even though it still has no true semantic memory.

## Try It Yourself: N-Grams, Frequencies & Sympathetic Marvin

Let's execute Kipling word/phrase counting, a 3-gram sliding window, and Marvin's 4-band sentiment + noun-phrase pluralizer in pure Python.

**N-Grams, Frequencies & Sympathetic Marvin**

```python
import re

poem = """What the moral? Who rides may read.
When the night is thick and the tracks are blind
A friend at a pinch is a friend, indeed,
But a fool to wait for the laggard behind.
Down to Gehenna or up to the Throne,
He travels the fastest who travels alone.""".lower()

words = re.findall(r"[a-z]+", poem)
print(f"Kipling 'the' count: {words.count('the')} | 'travels' count: {words.count('travels')}")

sentence = "the quick red fox jumped over the lazy brown dog".split()
trigrams = [" ".join(sentence[i:i+3]) for i in range(len(sentence) - 2)]
print(f"First 3 trigrams: {trigrams[:3]}")

POS = {"lovely": 0.5, "cool": 0.5, "great": 0.8, "best": 0.9}
NEG = {"sick": -0.6, "old": -0.1, "bad": -0.7}

def sympathetic_marvin(text):
    tokens = re.findall(r"[a-z]+", text.lower())
    scores = [POS.get(t, NEG.get(t, 0.0)) for t in tokens if t in POS or t in NEG]
    polarity = sum(scores) / len(scores) if scores else 0.1
    if polarity <= -0.5: prefix = "Oh dear, that sounds bad. "
    elif polarity <= 0:  prefix = "Hmm, that's not great. "
    elif polarity <= 0.5: prefix = "Well, that sounds positive. "
    else:                prefix = "Wow, that sounds great. "
    matches = re.findall(r"\b(?:a|an)\s+([a-z]+\s+[a-z]+)", text.lower())
    if matches:
        phrase = matches[-1]
        plural = phrase if phrase.endswith("s") else phrase + "s"
        return f"{prefix}Can you tell me more about {plural}?"
    return f"{prefix}Can you tell me more?"

for line in ["I went for a walk and saw a lovely cat", "I have an old hounddog but he is sick"]:
    print(f"> {line}")
    print(f"Marvin: {sympathetic_marvin(line)}")
```

**Expected Output:**

```text
Kipling 'the' count: 6 | 'travels' count: 2
First 3 trigrams: ['the quick red', 'quick red fox', 'red fox jumped']
> I went for a walk and saw a lovely cat
Marvin: Well, that sounds positive. Can you tell me more about lovely cats?
> I have an old hounddog but he is sick
Marvin: Hmm, that's not great. Can you tell me more about old hounddogs?
```
