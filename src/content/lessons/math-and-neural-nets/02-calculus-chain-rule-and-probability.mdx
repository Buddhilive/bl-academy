## Concept Walkthrough: Gradients, Uncertainty & Descent

### Derivatives & The Chain Rule

For a scalar loss $L(w)$, the derivative $\frac{dL}{dw}$ measures how fast $L$ changes when $w$ increases by a tiny step. Numerically, the central finite difference gives an accurate check:

$$\frac{dL}{dw} \approx \frac{L(w + h) - L(w - h)}{2h}, \qquad h = 10^{-5}$$

When functions are composed as $y = f(g(x))$, the **chain rule** multiplies local derivatives along the path:

$$\frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx} = f'(g(x)) \cdot g'(x)$$

Every modern autograd engine—from a 50-line Python `Value` class to PyTorch's `autograd`—automates this exact rule over a directed acyclic graph of operations.

### Probability, Bayes & Cross-Entropy

Classifiers output raw scores called **logits** $\mathbf{z}$, which **softmax** converts into a valid probability distribution by subtracting $\max(\mathbf{z})$ first to prevent floating-point overflow:

$$\text{softmax}(z_i) = \frac{e^{z_i - \max(\mathbf{z})}}{\sum_j e^{z_j - \max(\mathbf{z})}}$$

Given true distribution $p$ and predicted distribution $q$, **cross-entropy** measures the surprise (in nats) of using $q$ when reality follows $p$:

$$H(p, q) = -\sum_{i} p_i \log(q_i)$$

### Gradient Descent Update Rule

To minimize $L(\theta)$, step opposite to the gradient scaled by learning rate $\eta$:

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

| Concept | Formula / NumPy Pattern | Why It Matters in AI |
| :--- | :--- | :--- |
| Central difference | `(f(x + h) - f(x - h)) / (2 * h)` | Verifies custom backward passes |
| Stable softmax | `e = np.exp(z - z.max()); e / e.sum()` | Prevents `inf` / `NaN` in logits |
| Cross-entropy | `-np.sum(y_true * np.log(y_pred + 1e-12))` | Standard classification loss |
| Bayes posterior | `P(H\|E) = P(E\|H) * P(H) / P(E)` | Updates belief with new evidence |
| Gradient step | `w -= lr * grad` | Core parameter optimization loop |

Run this pure NumPy script to verify the chain rule numerically, compute stable softmax + cross-entropy, and minimize $f(x) = (x - 3)^2 + 2$:

  packages={["numpy"]}
  initialCode={`import numpy as np

# 1. Chain rule check for y = (3x + 1)^2 -> dy/dx = 6(3x + 1)
def f(x):
    return (3.0 * x + 1.0) ** 2

x = 2.0
h = 1e-5
num_grad = (f(x + h) - f(x - h)) / (2 * h)
ana_grad = 6.0 * (3.0 * x + 1.0)
print(f"Numerical grad: {num_grad:.6f} | Analytical grad: {ana_grad:.6f}")

# 2. Numerically stable softmax & cross-entropy
logits = np.array([1000.0, 1002.0, 999.0])
shifted = logits - np.max(logits)
probs = np.exp(shifted) / np.sum(np.exp(shifted))
y_true = np.array([0.0, 1.0, 0.0])
ce_loss = -np.sum(y_true * np.log(probs + 1e-12))
print("Softmax probs:", np.round(probs, 4), "| Cross-Entropy:", round(float(ce_loss), 4))

# 3. Gradient descent on g(w) = (w - 3)^2 + 2
w, lr = -4.0, 0.15
for step in range(15):
    grad = 2.0 * (w - 3.0)
    w -= lr * grad
print(f"Converged w = {w:.4f} (target: 3.0000)")`}

import numpy as np

# Bayes' Theorem: Medical test with 1% prevalence, 95% sensitivity, 5% false positive
p_disease = 0.01
p_pos_given_disease = 0.95
p_pos_given_healthy = 0.05

p_pos = p_pos_given_disease * p_disease + p_pos_given_healthy * (1 - p_disease)
