## Concept Walkthrough: Geometry Behind the Symbols

In `.ref/ai-engineering-from-scratch`, linear algebra is framed from first principles: every AI model is matrix math wearing a fancy hat. A **vector** $\mathbf{v} \in \mathbb{R}^n$ is both a point in $n$-dimensional space and a direction from the origin, with Euclidean length (L2 norm):

$$\|\mathbf{v}\|_2 = \sqrt{\sum_{i=1}^{n} v_i^2}$$

### Dot Products Measure Similarity

Given two vectors $\mathbf{a}, \mathbf{b} \in \mathbb{R}^n$, their dot product is:

$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i = \|\mathbf{a}\|_2 \|\mathbf{b}\|_2 \cos\theta$$

When $\mathbf{a} \cdot \mathbf{b} > 0$, the vectors point in a similar direction; when $\mathbf{a} \cdot \mathbf{b} = 0$, they are orthogonal (perpendicular); and when $\mathbf{a} \cdot \mathbf{b} < 0$, they point away from each other. Normalizing by the norms gives **cosine similarity**, the exact metric used in embedding search and attention scoring.

### Matrices Are Linear Transformations

Multiplying a matrix $W \in \mathbb{R}^{m \times n}$ by a vector $\mathbf{x} \in \mathbb{R}^n$ maps $\mathbf{x}$ from $\mathbb{R}^n$ into $\mathbb{R}^m$. Each row of $W$ computes one dot product with $\mathbf{x}$—meaning a linear neural network layer is simply $m$ parallel similarity checks against learned weight vectors.

| Operation | NumPy Syntax | Shape Rule | Neural Network Role |
| :--- | :--- | :--- | :--- |
| Dot product | `a @ b` or `np.dot(a, b)` | `(n,) @ (n,) -> ()` | Neuron pre-activation / similarity |
| Matrix multiply | `X @ W` | `(B, d_in) @ (d_in, d_out) -> (B, d_out)` | Batched linear layer forward pass |
| Transpose | `W.T` | `(m, n) -> (n, m)` | Backpropagation weight gradients |
| L2 Norm | `np.linalg.norm(v)` | `(n,) -> ()` | Normalization & weight decay |
| Cosine similarity | `(a @ b) / (norm(a) * norm(b))` | `(n,), (n,) -> [-1, 1]` | Embedding & attention alignment |

### 1. Try It in Browser (NumPy Vector & Matrix Math)

Run this pure NumPy snippet directly in your browser to compute cosine similarity and apply a 2D rotation-and-scale matrix transformation:

<PythonRunner
  client:visible
  title="Dot Products, Cosine Similarity & Matrix Transforms"
  packages={["numpy"]}
  initialCode={`import numpy as np

# Two 3D embedding vectors
a = np.array([1.0, 2.0, 0.5])
b = np.array([2.0, 3.5, 1.0])
c = np.array([-1.0, 0.5, 0.0])

def cosine_sim(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))

print(f"cos(a, b) = {cosine_sim(a, b):.4f}  (aligned)")
print(f"cos(a, c) = {cosine_sim(a, c):.4f}  (near orthogonal)")

# 2D linear transformation: 90-degree rotation + 2x scale
theta = np.pi / 2
R = 2.0 * np.array([
    [np.cos(theta), -np.sin(theta)],
    [np.sin(theta),  np.cos(theta)]
])
points = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
transformed = points @ R.T
print("Transformed points:\n", np.round(transformed, 3))`}

import numpy as np

# Batched linear layer: X (batch=4, d_in=3) -> Y (batch=4, d_out=2)
rng = np.random.default_rng(42)
X = rng.normal(size=(4, 3))
W = rng.normal(scale=0.5, size=(3, 2))
b = np.zeros((1, 2))

Y = X @ W + b  # Broadcasting b across the batch dimension
print("X shape:", X.shape, "W shape:", W.shape, "Y shape:", Y.shape)
