## Concept Walkthrough: Backward Pass Mechanics

### The Three Gradients of a Linear Layer

For a batched linear layer $Z = XW + \mathbf{b}$ where $X \in \mathbb{R}^{B \times d_{\text{in}}}$, $W \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}$, and upstream gradient $dZ = \frac{\partial L}{\partial Z} \in \mathbb{R}^{B \times d_{\text{out}}}$ arrives from the next layer:

$$\frac{\partial L}{\partial W} = X^T \, dZ, \qquad \frac{\partial L}{\partial \mathbf{b}} = \sum_{i=1}^{B} dZ_i, \qquad \frac{\partial L}{\partial X} = dZ \, W^T$$

Notice the symmetry: $dW$ updates the layer's weights, $d\mathbf{b}$ updates its bias, and $dX$ is passed backward to the previous layer.

### Activation Functions & Vanishing Gradients

| Activation | Formula | Derivative | Trade-Off |
| :--- | :--- | :--- | :--- |
| `Sigmoid` | $\sigma(z) = \frac{1}{1 + e^{-z}}$ | $\sigma(z)(1 - \sigma(z))$ | Max derivative is $0.25$; causes vanishing gradients in deep nets |
| `Tanh` | $\tanh(z)$ | $1 - \tanh^2(z)$ | Zero-centered, but still saturates for large $\|z\|$ |
| `ReLU` | $\max(0, z)$ | $\mathbf{1}_{z > 0}$ | Non-saturating for $z > 0$; fast and standard for hidden layers |
| `Softmax + CE` | $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$ | $\frac{\partial L}{\partial \mathbf{z}} = \frac{1}{B}(\mathbf{p} - \mathbf{y})$ | Clean, numerically stable gradient at output layer |

Run this pure NumPy backpropagation loop to train a 2-layer `Linear -> ReLU -> Linear` network on XOR from random weights:

<PythonRunner

  title="From-Scratch NumPy Backprop on XOR"
  packages={["numpy"]}
  initialCode={`import numpy as np

rng = np.random.default_rng(7)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)

W1 = rng.normal(0, 1.0, (2, 8))
b1 = np.zeros((1, 8))
W2 = rng.normal(0, 1.0, (8, 1))
b2 = np.zeros((1, 1))

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

lr = 0.5
for epoch in range(2000):
    # Forward
    z1 = X @ W1 + b1
    a1 = np.maximum(0.0, z1)  # ReLU
    z2 = a1 @ W2 + b2
    y_hat = sigmoid(z2)

    # Binary cross-entropy loss
    loss = -np.mean(y * np.log(y_hat + 1e-8) + (1 - y) * np.log(1 - y_hat + 1e-8))

    # Backward (BCE + Sigmoid simplifies to (y_hat - y) / B)
    dz2 = (y_hat - y) / len(X)
    dW2 = a1.T @ dz2
    db2 = dz2.sum(axis=0, keepdims=True)
    da1 = dz2 @ W2.T
    dz1 = da1 * (z1 > 0)
    dW1 = X.T @ dz1
    db1 = dz1.sum(axis=0, keepdims=True)

    # SGD step
    W2 -= lr * dW2; b2 -= lr * db2
    W1 -= lr * dW1; b1 -= lr * db1

print(f"Final loss: {loss:.4f}")
print("Predictions:", np.round(y_hat.ravel(), 3).tolist())`}

class ReLU:
    def forward(self, x):
        self.mask = (x > 0)
        return x * self.mask

    def backward(self, grad_out):
        return grad_out * self.mask
