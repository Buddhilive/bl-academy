## Concept Walkthrough: Spatial Filters, Sequences & Attention

### Convolutional Neural Networks (CNNs)

A 2D convolution slides a small learnable kernel (for example, $3 \times 3$) across an image. Early layers detect edges and textures; deeper layers combine them into shapes and objects—while sharing weights across every spatial location.

### Recurrent Neural Networks (RNNs & LSTMs)

An RNN processes a sequence one token $\mathbf{x}_t$ at a time, updating a hidden state $\mathbf{h}_t = \tanh(W \mathbf{x}_t + U \mathbf{h}_{t-1} + \mathbf{b})$. Because long sequences suffer from vanishing gradients, **LSTMs** add forget, input, and output gates. Still, token-by-token recurrence is hard to parallelize across long contexts.

### Scaled Dot-Product Self-Attention

Transformers let every token attend to every other token in a single matrix operation. Each token projects into **Query ($Q$)**, **Key ($K$)**, and **Value ($V$)** vectors:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right) V$$

Dividing by $\sqrt{d_k}$ keeps dot-product variance near $1$ so softmax does not saturate into near-zero gradients. For autoregressive language models, a causal mask $M$ sets future positions ($j > i$) to $-\infty$ before softmax. Adding **sinusoidal or learned positional encodings** restores word order without recurrence.

| Architecture | Core Operation | Sequence / Spatial Bias | Parallelism |
| :--- | :--- | :--- | :--- |
| `CNN` (`nn.Conv2d`) | Sliding local kernel | Translation equivariance (2D/1D grid) | High across spatial positions |
| `RNN` / `LSTM` | Recurrent state $\mathbf{h}_t$ | Strict left-to-right order | Sequential ($O(T)$ steps) |
| `Transformer` | $\text{softmax}(QK^T / \sqrt{d_k})V$ | Global pairwise + positional encoding | High ($O(1)$ sequential steps) |

rng = np.random.default_rng(123)
n_tokens, d_model, d_k = 4, 8, 4

X = rng.normal(size=(n_tokens, d_model))
Wq = rng.normal(scale=0.5, size=(d_model, d_k))
Wk = rng.normal(scale=0.5, size=(d_model, d_k))
Wv = rng.normal(scale=0.5, size=(d_model, d_k))

Q, K, V = X @ Wq, X @ Wk, X @ Wv
scores = (Q @ K.T) / np.sqrt(d_k)

# Causal mask: prevent token i from attending to future token j > i
mask = np.triu(np.ones((n_tokens, n_tokens)) * -1e9, k=1)
scores_masked = scores + mask

# Numerically stable row-wise softmax
exp_s = np.exp(scores_masked - scores_masked.max(axis=-1, keepdims=True))
attn_weights = exp_s / exp_s.sum(axis=-1, keepdims=True)
output = attn_weights @ V

print("Causal attention weights (rows sum to 1):\n", np.round(attn_weights, 3))
print("Output shape:", output.shape)`}

```python
import math
import torch
import torch.nn as nn

class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model=64, n_heads=4):
        super().__init__()
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.proj = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, T, C = x.shape
        qkv = self.qkv(x).view(B, T, 3, self.n_heads, self.d_k).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]
        att = (q @ k.transpose(-2, -1)) / math.sqrt(self.d_k)
        att = torch.softmax(att, dim=-1)
        out = (att @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.proj(out)
```
