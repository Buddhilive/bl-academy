Frank Rosenblatt's 1957 Perceptron proved that a machine could learn a linear decision boundary directly from examples. Yet a single neuron hits a famous wall: it cannot solve **XOR** because no single straight line separates `(0, 1)` and `(1, 0)` from `(0, 0)` and `(1, 1)`. Stacking layers with non-linear activations—a **Multi-Layer Perceptron (MLP)**—breaks through that wall.

## Concept Walkthrough: From Single Neuron to Hidden Layers

### The Single-Layer Perceptron

Given an input feature vector $\mathbf{x} \in \mathbb{R}^d$, weights $\mathbf{w} \in \mathbb{R}^d$, and bias $b$, a Perceptron computes:

$$\hat{y} = \text{step}(\mathbf{w} \cdot \mathbf{x} + b) = \begin{cases} 1 & \text{if } \mathbf{w} \cdot \mathbf{x} + b \ge 0 \\ 0 & \text{otherwise} \end{cases}$$

Whenever the prediction disagrees with target $y \in \{0, 1\}$, we nudge the weights toward the correct side:

$$\mathbf{w} \leftarrow \mathbf{w} + \eta (y - \hat{y}) \mathbf{x}, \qquad b \leftarrow b + \eta (y - \hat{y})$$

This converges whenever the classes are **linearly separable** (such as `AND` or `OR`).

### Why Hidden Layers Need Non-Linearity

If you stack two linear layers without an activation function, $W_2 (W_1 \mathbf{x}) = (W_2 W_1)\mathbf{x} = W_{\text{eff}} \mathbf{x}$—still just one linear boundary. Inserting a non-linear activation like **ReLU** or **tanh** between layers bends the coordinate space so the final layer can draw a straight line in the transformed representation.

| Architecture | Decision Boundary | Can Solve XOR? | Key Mechanism |
| :--- | :--- | :--- | :--- |
| Single Perceptron | Single hyperplane | No | Linear dot product + step |
| Deep Linear Net | Single hyperplane | No | $W_2 W_1$ collapses to one matrix |
| 2-Layer MLP (`tanh`/`ReLU`) | Piecewise / curved | Yes | Hidden layer warps feature space |

  initialCode={`import numpy as np

# 1. Single Perceptron learns AND gate
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y_and = np.array([0, 0, 0, 1], dtype=float)

w = np.zeros(2)
b = 0.0
lr = 0.1
for _ in range(15):
    for xi, target in zip(X, y_and):
        pred = 1.0 if (np.dot(xi, w) + b) >= 0 else 0.0
        err = target - pred
        w += lr * err * xi
        b += lr * err

and_preds = [1 if np.dot(xi, w) + b >= 0 else 0 for xi in X]
print("Perceptron AND preds:", and_preds, "| weights:", w, "bias:", b)

# 2. 2-Layer ReLU MLP solves XOR
# Hidden neuron 1: (x1 + x2 - 0.5) -> OR-like
# Hidden neuron 2: (x1 + x2 - 1.5) -> AND-like
W1 = np.array([[1.0, 1.0], [1.0, 1.0]])
b1 = np.array([-0.5, -1.5])
W2 = np.array([[1.0], [-2.0]])
b2 = np.array([-0.2])

h = np.maximum(0.0, X @ W1 + b1)  # ReLU hidden layer
out = (h @ W2 + b2).ravel()
xor_preds = (out > 0).astype(int)
print("2-Layer MLP XOR preds:", xor_preds.tolist())`}

```python
import numpy as np

# Modular Linear layer skeleton from scratch
class Linear:
    def __init__(self, in_features, out_features, rng):
        self.W = rng.normal(0.0, np.sqrt(2.0 / in_features), size=(in_features, out_features))
        self.b = np.zeros((1, out_features))

    def forward(self, x):
        self.x = x
        return x @ self.W + self.b
```
