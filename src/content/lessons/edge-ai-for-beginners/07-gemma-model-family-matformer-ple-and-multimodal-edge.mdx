You may know that fitting a capable multimodal model into 2 GB of mobile RAM sounds contradictory: vision encoders, large vocabularies, and 128K context windows all fight for the same limited accelerator SRAM. Google's **Gemma 3** and mobile-first **Gemma 3n** families solve this tension with two architectural breakthroughs: **MatFormer** (Matryoshka Transformer) nested sub-networks and **Per-Layer Embeddings (PLE)**.

Here is an overview of how Gemma scales from 1B text models to 27B single-GPU models and 2–3 GB mobile multimodal assistants.

---

## Gemma 3 & Gemma 3n Architectural Innovations

Derived from Gemini research (using distillation, RLHF, RLMF for math, and RLEF for code execution feedback), Gemma introduces three edge-critical features:

1. **128K Context with 5:1 Local-to-Global Attention**: Instead of running full quadratic global attention at every layer, Gemma 3 interleaves 5 local sliding-window attention layers (1,024-token span) for every 1 global attention layer, dramatically shrinking KV-cache memory at long contexts.
2. **MatFormer (Matryoshka Transformer)**: Like nested Russian dolls, a smaller sub-network (such as **E2B** with 2B effective parameters) sits cleanly inside a larger parent network (**E4B** with 4B effective parameters). Developers can slice an intermediate FFN width $\alpha_{\text{sub}} \in (0, 1]$ without retraining:
   $$
   P_{\text{effective}} = P_{\text{backbone}} + \alpha_{\text{sub}} \, P_{\text{FFN}}
   $$
3. **Per-Layer Embeddings (PLE)**: Standard transformer embedding tables sit in precious GPU/NPU memory. PLE moves per-layer token-level conditioning tables into fast CPU DRAM/flash storage, reducing accelerator SRAM consumption by:
   $$
   \Delta M_{\text{SRAM}} = L \cdot V \cdot d_{\text{ple}} \cdot \frac{b}{8}
   $$
   This allows Gemma 3n E2B and E4B to run with **2 GB to 3 GB** active accelerator footprints while supporting interleaved text, vision, and automatic speech recognition/translation (ASR/AST).

| Gemma Variant | Effective Footprint | Context Window | Modalities | Best Edge Target |
| :--- | :--- | :--- | :--- | :--- |
| **Gemma 3 1B** | ~0.7 GB (INT4) | 32K | Text | Ultra-lightweight CPU / mobile text tasks |
| **Gemma 3 4B / 12B / 27B** | 2.5–16 GB (INT4) | 128K | Text + Vision | Laptops, edge workstations, single-GPU servers |
| **Gemma 3n E2B / E4B** | **2 GB / 3 GB** active | 32K | Text + Vision + Audio | Smartphones, tablets, mobile NPUs |
