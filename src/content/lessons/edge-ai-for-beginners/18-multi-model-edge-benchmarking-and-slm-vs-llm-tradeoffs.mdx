## Streaming Telemetry & Pareto Efficiency

In streaming inference, total response time for $N$ generated tokens splits into two measurable phases—waiting for the *first* word to appear (**TTFT**) and the steady rhythm of the remaining $N-1$ words (**ITL**):

$$
T_{\text{stream}}(N) = \text{TTFT} + (N - 1) \cdot \text{ITL}, \qquad \text{TPS} = \frac{N - 1}{T_{\text{total}} - \text{TTFT}}
$$

- **TTFT (Time-To-First-Token)**: Dominated by network RTT (for cloud) or prompt prefill + cold model load (for local).
- **ITL (Inter-Token Latency)**: Dominated by DRAM bandwidth during autoregressive decode.
- **p95 Tail Latency**: Captures worst-case stalls (thermal throttling, garbage collection, or cold cache misses).

To compare heterogeneous candidates fairly across quality, speed, and memory footprint, compute the **Pareto Efficiency Score**:

$$
E(m) = \frac{\text{Quality}(m)}{\text{Latency}(m) \cdot \text{Memory}(m)}
$$

Think of $E(m)$ as "bang for your buck": higher accuracy/quality raises the score, while slower latency or heavier RAM usage shrinks it.

| Metric | Micro SLM (`Qwen2.5-0.5B`) | Small SLM (`Phi-4-mini-3.8B`) | Cloud LLM (`gemini-2.5-flash`) |
| :--- | :--- | :--- | :--- |
| **TTFT** | ~25–60 ms (local) | ~90–230 ms (local) | ~250–600 ms (network) |
| **Memory on Device** | ~0.45 GB (Q4_K_M) | ~2.2 GB (Q4_K_M) | 0 GB (remote) |
| **Offline Capability** | 100% | 100% | None |
| **Best Role** | Intent classification & extraction | Local RAG, coding & tool calling | Complex synthesis & fallback |

When integrating directly over HTTP without heavy SDKs, always include a **health check** (`/v1/models`), **streaming SSE parser**, and **exponential backoff retry** for cold-start transients.

## Try It Yourself: Multi-Model TTFT, TPS & p95 Benchmark Harness

Run this Python benchmark harness to compute TTFT, decode TPS, p95 latency, and the Pareto efficiency winner across three candidate models.

**Multi-Model Edge Benchmark & Pareto Ranker**

```python
def percentile_95(values):
    s = sorted(values)
    idx = min(len(s) - 1, int(0.95 * len(s)))
    return s[idx]

runs = [
    ("qwen2.5-0.5b", [165.0, 175.0, 185.0], 45.0, 21, 0.78, 0.45),
    ("phi-4-mini",   [410.0, 430.0, 450.0], 150.0, 21, 0.90, 2.20),
    ("gemini-flash", [560.0, 590.0, 710.0], 442.0, 21, 0.95, 1.00),  # 1.0GB nominal cloud equiv
]

best_name, best_eff = None, -1.0
for name, totals, ttft, n_toks, qual, mem_gb in runs:
    avg_ms = sum(totals) / len(totals)
    p95_ms = percentile_95(totals)
    tps = (n_toks - 1) / ((avg_ms - ttft) / 1000.0)
    eff = qual / ((avg_ms / 1000.0) * (mem_gb + 1.0))
    if eff > best_eff:
        best_eff, best_name = eff, name
    print(f"{name:14s} | Avg={avg_ms:.1f}ms | p95={p95_ms:.1f}ms | TPS={tps:.1f} | Eff={eff:.2f}")

print(f"Pareto Efficiency Winner: {best_name}")
```

**Expected Output:**

```text
qwen2.5-0.5b   | Avg=175.0ms | p95=185.0ms | TPS=153.8 | Eff=3.07
phi-4-mini     | Avg=430.0ms | p95=450.0ms | TPS=71.4 | Eff=0.65
gemini-flash   | Avg=620.0ms | p95=710.0ms | TPS=112.4 | Eff=0.77
Pareto Efficiency Winner: qwen2.5-0.5b
```
