You may know that full fine-tuning updates every single weight in a neural network, requiring optimizer states and gradients that easily exceed 60 GB of VRAM even for a 3.8B model. **Parameter-Efficient Fine-Tuning (PEFT)** using **LoRA (Low-Rank Adaptation)** and **QLoRA (4-bit Quantized LoRA)** shrinks that requirement so you can specialize an edge SLM on a single free 15 GB Colab T4 GPU.

Here is an overview of how LoRA rank decomposition works, how QLoRA fits multi-billion-parameter tuning into 15 GB, and how to merge adapters for zero-overhead edge inference.

---

## Full Fine-Tuning vs. LoRA vs. QLoRA

| Method | Base Weights | Trainable Params | Optimizer VRAM (3.8B Model) | Best Use Case |
| :--- | :--- | :--- | :--- | :--- |
| **Full Fine-Tuning** | FP16 / BF16 | 100% | ~60 GB+ | Multi-GPU pretraining or massive domain shift |
| **LoRA** | Frozen FP16 | ~0.2% – 1.5% | ~10–12 GB | Fast domain adaptation on 16–24 GB GPUs |
| **QLoRA (NF4)** | **Frozen 4-bit NormalFloat** | ~0.2% – 1.5% (FP16) | **~4.5–6 GB** | Fine-tuning 3.8B–8B SLMs on **Colab Free T4** |

### Low-Rank Weight Decomposition & Zero-Overhead Merging

Instead of updating a dense weight matrix $W_0 \in \mathbb{R}^{d \times k}$ directly, LoRA freezes $W_0$ and injects two small trainable matrices $B \in \mathbb{R}^{d \times r}$ and $A \in \mathbb{R}^{r \times k}$ where rank $r \ll \min(d, k)$:

$$
h = W_0 x + \frac{\alpha}{r} B A x
$$

The trainable parameter fraction for a linear layer is:

$$
\rho_{\text{LoRA}} = \frac{r(d + k)}{d \cdot k}
$$

For a $3072 \times 3072$ projection with rank $r = 8$, LoRA trains only **0.52 percent** of the weights! And once training finishes, you do not need to ship separate adapter files to the edge device: simply compute $W_{\text{merged}} = W_0 + \frac{\alpha}{r} B A$ (`peft_model.merge_and_unload()`), then export the merged model to **GGUF `Q4_K_M`** or **ONNX INT4** with zero extra runtime latency.

base_params = d * k

for r in (4, 8, 16):
    lora_params = r * (d + k)
    pct = (lora_params / base_params) * 100.0
    print(f"Rank r={r:2d} | Trainable Params={lora_params:8,d} / {base_params:,d} ({pct:.2f}%)")

# Verify W_0*x + (alpha/r)*B*A*x == (W_0 + (alpha/r)*B*A)*x
W0 = [[1.0, 0.5], [-0.5, 1.0]]
A = [[0.2, 0.1]]   # 1 x 2 (r=1, k=2)
B = [[0.5], [1.0]] # 2 x 1 (d=2, r=1)
x = [0.5, 1.0]
alpha, r_small = 2.0, 1
scale = alpha / r_small

def matvec(M, v):
    return [sum(M[i][j] * v[j] for j in range(len(v))) for i in range(len(M))]

# Unmerged path
ax = matvec(A, x)
bax = matvec(B, ax)
w0x = matvec(W0, x)
unmerged = [w0x[i] + scale * bax[i] for i in range(2)]

# Merged path: W_merged = W0 + scale * (B @ A)
W_merged = [
    [W0[i][j] + scale * B[i][0] * A[0][j] for j in range(2)]
    for i in range(2)
]
merged = matvec(W_merged, x)
max_diff = max(abs(a - b) for a, b in zip(unmerged, merged))

print(f"Unmerged LoRA Output: [{unmerged[0]:.4f}, {unmerged[1]:.4f}]")
print(f"Merged Edge Output:   [{merged[0]:.4f}, {merged[1]:.4f}] | Max Diff: {max_diff:.2e}")`}
