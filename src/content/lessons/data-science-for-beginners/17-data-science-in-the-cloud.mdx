## Cloud Topologies & Service Models (IaaS, PaaS, SaaS)

Cloud environments are organized by who owns the hardware and how much infrastructure you manage yourself:

| Category | Model | What You Manage vs. What the Provider Manages |
| :--- | :--- | :--- |
| **Deployment** | **Public Cloud** | Shared third-party infrastructure over the internet (AWS, GCP, Azure) |
| **Deployment** | **Private Cloud** | Dedicated infrastructure on a private network for a single organization |
| **Deployment** | **Hybrid Cloud** | Combines on-premises datacenters with public cloud burst capacity |
| **Service** | **IaaS** | Rent raw VMs, storage, and networking; you manage OS and runtimes |
| **Service** | **PaaS** | Managed dev/notebook environment (e.g., Google Colab); focus purely on code and data |
| **Service** | **SaaS** | Ready-to-use web applications over the internet (e.g., BI dashboards) |

Data teams adopt the cloud for seven core advantages: **Innovation** (managed AI APIs), **Flexibility**, **Budget** (zero upfront hardware), **Scalability**, **Productivity**, **Reliability** (automated backups & disaster recovery), and **Security**.

## Two Cloud Data Science Scenarios (Open-Source & Gemini API)

1. **Real-Time Social Media Sentiment Streaming**: Ingesting live hashtag streams, computing rolling volume and sentiment windows, and storing structured metrics in an analytical database like **DuckDB**.
2. **Scientific Paper Knowledge Extraction**: Parsing medical research abstracts (like COVID-19 literature) to extract structured diagnoses, treatments, and dosages using **Google AI Studio Free Tier** (`google-genai` SDK + `GEMINI_API_KEY` stored in Colab Secrets). To set up your free key, visit [aistudio.google.com/apikey](https://aistudio.google.com/apikey), generate a key, paste it into Colab's **Secrets** panel as `GEMINI_API_KEY`, and toggle **Notebook access** on.

```python
from google.colab import userdata
from google import genai

client = genai.Client(api_key=userdata.get("GEMINI_API_KEY"))
resp = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Extract JSON {sentiment, topic} from: Open-source Python data tools are super fast!"
)
print(resp.text)
```

## Try It Yourself: Streaming Sentiment & Paper Extractor

Run this pure-Python cloud analytics simulator to aggregate a sliding window of social media hashtag sentiment and extract structured medical entities from a research abstract.

**Cloud Stream Window & Medical Paper Extractor**

```python
stream = [
    {"tag": "#datascience", "score": 0.9},
    {"tag": "#datascience", "score": 0.8},
    {"tag": "#python", "score": 0.6},
]

agg = {}
for msg in stream:
    agg.setdefault(msg["tag"], []).append(msg["score"])

print("=== Real-Time Hashtag Sentiment Window ===")
for tag, scores in agg.items():
    print(f"{tag}: {len(scores)} posts | avg_sentiment={sum(scores)/len(scores):+.2f}")

abstract = "Patients receiving dexamethasone and supplemental oxygen showed reduced mortality."
known_treatments = ["dexamethasone", "remdesivir", "oxygen"]
found = [t for t in known_treatments if t in abstract.lower()]
outcome = "reduced mortality" if "reduced mortality" in abstract.lower() else "inconclusive"

print("\n=== Scientific Paper Structured Extraction ===")
print(f"Treatments: {found} | Outcome: {outcome}")
```

**Expected Output:**

```text
=== Real-Time Hashtag Sentiment Window ===
#datascience: 2 posts | avg_sentiment=+0.85
#python: 1 posts | avg_sentiment=+0.60

=== Scientific Paper Structured Extraction ===
Treatments: ['dexamethasone', 'oxygen'] | Outcome: reduced mortality
```
