## Try It Yourself: Gender Shades Audit & Literary Mood Analyzer

Run this pure-Python capstone suite to audit intersectional error rates (inspired by *Gender Shades*), classify seasonal tone in Emily Dickinson verses, and filter a STAC satellite catalog by cloud cover.

**Real-World Fairness, Humanities & STAC Suite**

```python
# 1. Intersectional Subgroup Error Audit
subgroups = {"Lighter Male": 0.8, "Darker Female": 34.7}
gap = subgroups["Darker Female"] - subgroups["Lighter Male"]
print("=== Intersectional Error Rate Audit (Gender Shades) ===")
print(f"Lighter Male Error: {subgroups['Lighter Male']}% | Darker Female Error: {subgroups['Darker Female']}% | Gap: {gap:.1f}%")

# 2. Digital Humanities: Poem Sentiment
poem = "Hope is the thing with feathers that perches in the soul and sings the tune without the words."
positive_words = {"hope", "sings", "warm", "light", "joy"}
score = sum(w.strip(".,") in positive_words for w in poem.lower().split())
tone = "Optimistic" if score > 0 else "Melancholic"
print("\n=== Emily Dickinson Tone Classifier ===")
print(f"Poem 1 ('Hope is the thing with feathers'): {tone} (score +{score})")

# 3. Sustainability: STAC Geospatial Metadata Filter
scenes = [
    {"id": "S2A_20261108_T10SEG", "cloud_cover": 64.2},
    {"id": "S2A_20261110_T10SEG", "cloud_cover": 4.5},
]
clear = [s["id"] for s in scenes if s["cloud_cover"] < 15.0]
print("\n=== Open STAC Satellite Catalog Filter ===")
print(f"Found {len(clear)} low-cloud Sentinel-2 scene(s): {clear}")
```

**Expected Output:**

```text
=== Intersectional Error Rate Audit (Gender Shades) ===
Lighter Male Error: 0.8% | Darker Female Error: 34.7% | Gap: 33.9%

=== Emily Dickinson Tone Classifier ===
Poem 1 ('Hope is the thing with feathers'): Optimistic (score +2)

=== Open STAC Satellite Catalog Filter ===
Found 1 low-cloud Sentinel-2 scene(s): ['S2A_20261110_T10SEG']
```
