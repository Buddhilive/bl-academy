## Pandas `Series` & Index-Aligned Arithmetic

A **Series** is a 1D sequence of values paired with an **Index** (integers, strings, or `pd.date_range` timestamps). Unlike plain Python lists, Pandas aligns operations by index:

- If you add daily ice-cream sales (`items_sold`) to weekly party packs (`additional_items`, `freq="W"`) using `+`, non-Sunday dates turn into `NaN` (*Not a Number*) because adding anything to a missing index entry produces `NaN`.
- Using `items_sold.add(additional_items, fill_value=0)` fills missing weekly entries with `0` before summing.
- Calling `.resample("1ME").mean()` aggregates daily timestamps into monthly averages.

## Core `DataFrame` Operations

A **DataFrame** is a 2D table of `Series` sharing the same index. Here is a quick reference of the operations you'll use daily:

| Operation | Syntax | Key Gotcha |
| :--- | :--- | :--- |
| **Select Column / Subset** | `df['A']` or `df[['B', 'A']]` | Single bracket returns a `Series`; double bracket returns a `DataFrame` |
| **Boolean Filtering** | `df[(df['A'] > 5) & (df['A'] < 7)]` | Must use `&` (not `and`) and wrap each condition in `()` |
| **Vectorized Column** | `df['DivA'] = df['A'] - df['A'].mean()` | Fast element-wise math across the entire column |
| **Row-wise Function** | `df['LenB'] = df['B'].apply(len)` | Calling `len(df['B'])` assigns total column length to every row! |
| **Positional Slice** | `df.iloc[:5]` | Selects the first 5 rows by integer position |
| **Group & Aggregate** | `df.groupby('LenB').aggregate({'A': 'mean'})` | Pivot-table summaries across groups |

## Try It Yourself: Time-Series Resampling & GroupBy Aggregation

Run this pure-Python implementation of Pandas-style index alignment, row-wise `.apply(len)`, `groupby` aggregation, and medical abstract keyword counting in Google Colab or locally.

**Index Alignment, GroupBy & Text Extraction**

```python
# 1. Index-aligned Series addition with fill_value=0
daily_sales = {"2020-01-05": 35, "2020-01-06": 42}
weekly_party = {"2020-01-05": 10}
total = {d: daily_sales[d] + weekly_party.get(d, 0) for d in daily_sales}
print("=== Index-Aligned Weekly + Daily Sales ===")
print(f"Day 1 (Sun): {daily_sales['2020-01-05']} + {weekly_party.get('2020-01-05', 0)} = {total['2020-01-05']}")
print(f"Day 2 (Mon): {daily_sales['2020-01-06']} + {weekly_party.get('2020-01-06', 0)} = {total['2020-01-06']}")

# 2. DataFrame GroupBy LenB Aggregation
rows = list(zip(range(1, 10), ["I", "like", "to", "use", "Python", "and", "Pandas", "very", "much"]))
groups = {}
for a_val, b_val in rows:
    groups.setdefault(len(b_val), []).append(a_val)

print("\n=== GroupBy LenB Summary ===")
for k in [1, 4, 6]:
    vals = groups[k]
    print(f"Len {k}: count={len(vals)}, mean_A={sum(vals)/len(vals):.2f}")

# 3. Unstructured Medical Abstract Keyword Extraction
abstracts = [
    "Clinical trial of remdesivir and dexamethasone in hospitalized patients.",
    "Early oxygen therapy paired with dexamethasone and remdesivir improved outcomes.",
]
targets = ["dexamethasone", "remdesivir", "oxygen"]
counts = {t: sum(t in ab.lower() for ab in abstracts) for t in targets}
print("\n=== Extracted Medical Treatments ===")
print(" | ".join(f"{k}: {v}" for k, v in counts.items()))
```

**Expected Output:**

```text
=== Index-Aligned Weekly + Daily Sales ===
Day 1 (Sun): 35 + 10 = 45
Day 2 (Mon): 42 + 0 = 42

=== GroupBy LenB Summary ===
Len 1: count=1, mean_A=1.00
Len 4: count=3, mean_A=6.33
Len 6: count=2, mean_A=6.00

=== Extracted Medical Treatments ===
dexamethasone: 2 | remdesivir: 2 | oxygen: 1
```
