Real-world data rarely arrives spotless. Dates appear in conflicting formats, survey respondents skip fields, and joining two tables creates duplicate rows. Feeding that "dirty" data straight into a model guarantees weak or biased predictions. **Data Preparation** is where we turn messy raw inputs into clean, consistent, reusable datasets.

In this lesson, we'll inspect DataFrame schemas on the classic **Iris** dataset, unpack how Pandas handles `NaN` versus `None`, and practice dropping, imputing, and deduplicating records.

---

## Why Clean Data? & Quick DataFrame Inspection

Cleaning data pays off in three ways: **ease of reuse** (normalized formats are easy to query and share), **consistency** (datasets from different sources merge cleanly), and **model accuracy**.

When you first load a large table, say 60,000 rows by 400 columns, start with three quick inspection methods:

- `df.info()`: Prints row count, column names, non-null counts, `Dtype` (e.g., `float64`), and memory footprint.
- `df.head()` / `df.tail()`: Previews the first 5 and last 5 rows to spot formatting quirks immediately.

---

## Missing Data: `NaN` vs. `None` & Detection

Pandas represents missing values in two ways:
1. **`NaN` (Not a Number)**: An IEEE 754 floating-point sentinel. Adding `np.nan` to an integer column forces Pandas to **upcast** that column to `float64`.
2. **`None`**: Python's native null object, used in non-numeric (`object`) columns.

Crucially, `0` (integer zero) and `''` (empty string) are **valid values**, not null! Calling `.isnull()` or `.notnull()` returns a Boolean mask flagging only `NaN` and `None`.

---

## Dropping, Imputing & Deduplicating

| Technique | Pandas Method | Behavior & Use Case |
| :--- | :--- | :--- |
| **Drop Rows/Cols** | `df.dropna(axis='rows', how='any', thresh=3)` | Drops rows with any null (`how='any'`), all nulls (`how='all'`), or fewer than `thresh` non-nulls |
| **Constant Fill** | `df.fillna(0)` | Replaces all nulls with a fixed constant |
| **Forward Fill (`ffill`)** | `df.ffill()` | Propagates the previous valid value forward along rows or `axis=1` |
| **Back Fill (`bfill`)** | `df.bfill()` | Propagates the next valid value backward to fill earlier gaps |
| **Detect Duplicates** | `df.duplicated()` | Returns Boolean mask (`True` for repeated rows) |
| **Remove Duplicates** | `df.drop_duplicates(subset=['letters'])` | Keeps first occurrence across all columns or a specified `subset` |

## Try It Yourself: Null Detection, Imputation & Deduplication

Run this pure-Python cleaning pipeline to see why `0` and `''` survive `isnull()`, how `thresh=3` filters sparse rows, how `ffill`/`bfill` propagate values, and how `drop_duplicates(subset=['letters'])` behaves.

**Missing Value Imputation & Deduplication**

```python
# 1. isnull() distinguishes 0 and '' from None/NaN
s = [0, None, "", None]
print("=== isnull() Mask on [0, None, '', None] ===")
print([x is None for x in s])

# 2. dropna(thresh=3)
matrix = [
    [1.0, None, 7, None],
    [2.0, 5.0,  8, None],
    [None, 6.0, 9, None],
]
kept = [row for row in matrix if sum(v is not None for v in row) >= 3]
print("\n=== thresh=3 Row Filter (4 cols) ===")
print(f"Kept rows: {kept}")

# 3. Forward Fill (ffill)
series = [1.0, None, 2.0, None, 3.0]
ffilled, last = [], None
for v in series:
    if v is not None:
        last = v
    ffilled.append(last)
print("\n=== Forward Fill (ffill) on [1.0, None, 2.0, None, 3.0] ===")
print(ffilled)

# 4. drop_duplicates(subset=['letters'])
records = [("A", 1), ("B", 2), ("A", 1), ("B", 3), ("B", 3)]
seen, deduped = set(), []
for letter, num in records:
    if letter not in seen:
        seen.add(letter)
        deduped.append((letter, num))
print("\n=== drop_duplicates(subset=['letters']) ===")
print(deduped)
```

**Expected Output:**

```text
=== isnull() Mask on [0, None, '', None] ===
[False, True, False, True]

=== thresh=3 Row Filter (4 cols) ===
Kept rows: [[2.0, 5.0, 8, None]]

=== Forward Fill (ffill) on [1.0, None, 2.0, None, 3.0] ===
[1.0, 1.0, 2.0, 2.0, 3.0]

=== drop_duplicates(subset=['letters']) ===
[('A', 1), ('B', 2)]
```
