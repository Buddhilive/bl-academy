Once your agent system grows beyond a single loop, you need clean primitives for **durability**, **middleware interception**, and **explicit graph control flow**. Rather than locking into a proprietary runtime, we can implement every one of these production workflow patterns using open-source Python, **LangGraph**, and **FastAPI**.

---

## Core Workflow & Middleware Primitives

1. **5 Orchestration Topologies**: *Sequential*, *Concurrent*, *Group Chat*, *Handoff*, and *Magentic* (manager-led dynamic task lists).
2. **Serializable Agent Threads**: Calling `thread = agent.get_new_thread()`, `thread.serialize()`, and `agent.deserialize_thread(data)` lets long-running conversations pause and resume across restarts (mirroring `LangGraph`'s `MemorySaver` / `SqliteSaver` checkpointers).
3. **Composable Middleware**:
   - **Function Middleware (`FunctionInvocationContext`, `next`)**: Runs pre- and post-hooks around every tool call for logging, RBAC, or argument validation.
   - **Chat Middleware (`ChatContext`, `next`)**: Intercepts outbound LLM `messages` arrays for PII redaction or token auditing.
4. **Graph Workflows (`WorkflowBuilder`)**: Connect AI agents and Python **Executors** using five edge types—**Direct**, **Conditional**, **Switch-Case** (e.g., VIP priority routing), **Fan-Out**, and **Fan-In**—while emitting typed lifecycle events (`WorkflowStartedEvent`, `ExecutorInvokeEvent`, `ExecutorCompleteEvent`, `RequestInfoEvent`, `WorkflowOutputEvent`, `WorkflowErrorEvent`).

| Hosting Protocol | Endpoint | Best Used For |
| :--- | :--- | :--- |
| **`Responses` Protocol** | `POST /responses` | OpenAI-compatible chat, streaming, `previous_response_id` threading, and `interrupt()` HITL |
| **`Invocations` Protocol** | `POST /invocations` | Custom JSON payloads, webhook triggers, or non-conversational batch jobs |
