## Setting Up Google Colab & Local Python Environments

Every hands-on notebook in this course runs out of the box on Google Colab Free Tier. If you also want to clone a large multi-lesson repository locally without downloading gigabytes of translation history, Git's **shallow** and **sparse** checkout flags keep your workspace fast and lightweight:

```bash
# Shallow clone (minimal history)
git clone --depth 1 https://github.com/<your-username>/<repo>.git

# Partial sparse clone (fetch only specific lesson folders)
git clone --depth 1 --filter=blob:none --sparse https://github.com/<your-username>/<repo>.git
cd <repo>
git sparse-checkout set 00-course-setup 01-intro-to-ai-agents
```

For local Python 3.12+ development, always isolate your dependencies in a virtual environment before installing packages:

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install google-genai langgraph chromadb pydantic python-dotenv mcp
```

## Obtaining Your Free Google AI Studio API Key

Instead of paying for enterprise cloud subscriptions, every cloud LLM call in this course uses **Google AI Studio Free Tier**:

1. Open [aistudio.google.com](https://aistudio.google.com/) and sign in with your Google account.
2. Click **Get API key** → **Create API key** and copy the generated key (`AIza...`).
3. In **Google Colab**, open the **Secrets** (key icon) panel in the left sidebar, add a secret named `GEMINI_API_KEY`, paste your key, and toggle **Notebook access** ON.
4. On your local machine, store `GEMINI_API_KEY=AIza...` inside a gitignored `.env` file and load it with `python-dotenv`.

```python
import os
from google import genai

def get_gemini_client():
    api_key = None
    try:
        from google.colab import userdata
        api_key = userdata.get("GEMINI_API_KEY")
    except Exception:
        api_key = os.environ.get("GEMINI_API_KEY")
    return genai.Client(api_key=api_key) if api_key else None
```

## Open-Source Vector Search & Multi-Provider Routing

Later lessons build **Agentic RAG** (Lesson 06) and **Scalable Production Agents** (Lesson 17) backed by semantic search. We pair `gemini-embedding-001` with **ChromaDB** (or an in-memory cosine-similarity store when running quick demos), eliminating external search service provisioning.

Because modern agent SDKs speak standard OpenAI-compatible HTTP schemas, you can also point the same client configuration at alternative providers:
- **Google Gemini OpenAI-Compatible Endpoint**: `https://generativelanguage.googleapis.com/v1beta/openai/`
- **Large-Context Endpoints (e.g., MiniMax-M3)**: Up to 204K-token context windows via `https://api.minimax.io/v1`
- **Open-Weight Inference (e.g., Novita AI)**: Open-source families (`deepseek`, `qwen`, `kimi`) via `https://api.novita.ai/openai/v1`
- **Local On-Device Runtime (Ollama)**: Private local inference at `http://127.0.0.1:11434/v1` with `api_key="not-required"`

### SSL Certificate Troubleshooting on macOS / Corporate Networks

If Python raises `ssl.SSLCertVerificationError: certificate verify failed` during network calls, run Python's `Install Certificates.command` on macOS or inject your OS trust store cleanly with `truststore` (never disable SSL verification in production):

```python
import truststore
truststore.inject_into_ssl()
```
