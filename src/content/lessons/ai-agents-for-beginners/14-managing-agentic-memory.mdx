Without memory, every conversation with an AI agent starts from zero—forcing users to repeat their preferences, constraints, and history over and over again. **Memory** is what turns stateless bots into reflective, proactive, self-improving assistants.

---

## The 7 Types of AI Agent Memory

| Memory Type | Scope & Lifetime | Travel Agent Example |
| :--- | :--- | :--- |
| **Working Memory** | Current reasoning step / scratchpad | Holds active request *"Book a trip to Paris"* |
| **Short-Term Memory** | Single conversation session (`AgentSession`) | Resolves *"What about accommodation there?"* $\rightarrow$ *"Paris"* |
| **Long-Term Memory** | Persists across sessions in a DB/vector store | Recalls *"Ben likes mountain-view coffee and avoids advanced ski slopes due to injury"* |
| **Persona Memory** | Reinforces the agent's consistent role/tone | Maintains *"expert ski planner"* voice |
| **Episodic / Workflow** | Records action sequences, successes & failures | Remembers a failed flight booking attempt to avoid repeating it |
| **Entity Memory** | Tracks structured people, places, and things | Extracts `"Paris"`, `"Eiffel Tower"`, `"Le Chat Noir"` |
| **Structured RAG** | Parses dense structured fields from raw sources | Extracts flight date, time, and airline from confirmation emails |

---

## Mem0 Two-Phase Pipeline & Cognee Knowledge Graphs

Two open-source memory architectures solve persistent recall at scale:

1. **Mem0 (Two-Phase Extraction & Update)**: In *Phase 1 (Extraction)*, an LLM summarizes new conversation turns into candidate facts. In *Phase 2 (Update)*, it compares those candidates against existing memories and executes `ADD`, `UPDATE`, `DELETE`, or `NOOP` operations across hybrid vector, key-value, and graph stores.
2. **Cognee (Dual-Store Semantic Knowledge Graph)**: Transforms structured and unstructured data into an entity-relationship graph $G = (V, E)$ backed by vector embeddings, enabling **hybrid retrieval** that blends semantic similarity with graph traversal.

### Self-Improving Knowledge Observer & Latency Optimization

To make agents self-improving without slowing down user replies, run a background **Knowledge Agent** that observes the main dialogue. Use a fast, low-cost SLM (`gemini-2.5-flash-lite`) as a gate to check whether a turn contains store-worthy facts, and archive stale entries to cold storage.

print(f"[KnowledgeObserver] SLM gate={gate} -> Saved episodic preference for next session.")`}
