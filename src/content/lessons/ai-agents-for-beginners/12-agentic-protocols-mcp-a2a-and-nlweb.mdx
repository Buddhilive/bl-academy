As AI agents move into multi-vendor ecosystems, custom one-off integrations break down. Open **Agentic Protocols** standardize how agents connect to tools, collaborate with external agents, and query websites—without brittle glue code.

In this lesson, we unify the three core protocols shaping modern agent architectures: **Model Context Protocol (MCP)**, **Agent-to-Agent (A2A)**, and **Natural Language Web (NLWeb)**.

---

## Comparing MCP, A2A, and NLWeb

| Protocol | Primary Connection | Core Primitives / Components | Travel Booking Role |
| :--- | :--- | :--- | :--- |
| **MCP** | Agent (Host/Client) $\leftrightarrow$ Tools & Data | **Tools** (actions), **Resources** (read-only data), **Prompts** (templates) | Travel agent discovers `search_flights` & `book_flight` on an Airline MCP server |
| **A2A** | Agent $\leftrightarrow$ Remote Agent | **Agent Card**, **Agent Executor**, **Artifact**, **Event Queue** | Travel agent delegates hotel & car booking to external company agents |
| **NLWeb** | Human / Agent $\leftrightarrow$ Website | **NLWeb Protocol** (Schema.org JSON), **MCP `ask` endpoint**, **Vector DB** | Queries a Honolulu hotel catalog with natural language and zero hallucination |

---

## How Each Protocol Works in Practice

1. **Model Context Protocol (MCP)**: Operates on a client-server model where a Host creates 1:1 Clients to connect to Servers. Agents dynamically discover tool schemas at runtime, switch underlying LLMs freely, and use standardized authentication.
2. **Agent-to-Agent Protocol (A2A)**: Connects independent agents across organizations. Each remote agent publishes an **Agent Card** (name, skills, endpoint URL, streaming capabilities). The calling agent sends context to an **Agent Executor**, receives progress via an **Event Queue** so long-running connections never drop, and collects the finished **Artifact**.
3. **Natural Language Web (NLWeb)**: Turns any website into an AI-native catalog. Site data (Schema.org/RSS) is embedded into a vector database (`ChromaDB` / `Qdrant`). Both humans in a web chat and external AI agents calling the built-in MCP `ask()` method get grounded JSON responses.
