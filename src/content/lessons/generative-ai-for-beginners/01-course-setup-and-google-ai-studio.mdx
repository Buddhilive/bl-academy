## Step-by-Step: Getting Your Free Google AI Studio API Key

You do not need a credit card or enterprise cloud subscription to complete this entire 22-lesson course. **Google AI Studio** gives developers a generous free tier for `gemini-2.5-flash`, `gemini-2.5-pro`, and `gemini-embedding-001` via the official `google-genai` Python SDK.

1. **Sign in to Google AI Studio**: Open [aistudio.google.com](https://aistudio.google.com/) in your browser and sign in with a standard Google account.
2. **Create an API Key**: Click **Get API key** in the left navigation rail, then select **Create API key**.
3. **Copy & Store Safely**: Copy the generated key (starting with `AIza...`). Never paste this string directly into `.py` files, `.ipynb` cells, or `git commit` history.

### Storing `GEMINI_API_KEY` in Google Colab Secrets

Every companion notebook in this course is designed to run on **Google Colab Free Tier**:

1. Open any notebook via the **Open with Google Colab** button.
2. Click the **Key icon (Secrets)** in the left sidebar of Colab.
3. Click **Add new secret**, set **Name** to `GEMINI_API_KEY`, paste your key as **Value**, and toggle **Notebook access** ON.
4. Read the key cleanly inside Python using `google.colab.userdata`:

```python
from google.colab import userdata
from google import genai

api_key = userdata.get("GEMINI_API_KEY")
client = genai.Client(api_key=api_key)
```

## Local Python Setup & `.env` Secret Hygiene

If you prefer running scripts locally on your own machine, isolate your dependencies in a virtual environment and load secrets from a `.env` file excluded by `.gitignore`:

```bash
python -m venv .venv
# Activate on Windows (PowerShell): .venv\Scripts\Activate.ps1
# Activate on macOS/Linux: source .venv/bin/activate
pip install google-genai python-dotenv
```

Create a `.env` file in your project root (and verify `.env` is listed in `.gitignore`):

```text
GEMINI_API_KEY=your_actual_api_key_here
```

Then load it in Python with `python-dotenv`:

```python
import os
from dotenv import load_dotenv
from google import genai

load_dotenv()
client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
```

### Rate Limits & Exponential Backoff Math

Free-tier APIs enforce **Requests Per Minute (RPM)**, **Tokens Per Minute (TPM)**, and **Requests Per Day (RPD)** quotas. When building batch pipelines (like embedding 500 document chunks), always throttle requests or apply truncated **exponential backoff** with jitter when a `429 Too Many Requests` status occurs:

$$t_k = \min\Big(t_{\max},\; t_0 \cdot 2^k\Big) + \epsilon_{\text{jitter}}$$

In plain English: $t_0$ is your starting wait time in seconds (e.g., `1s`), $k$ is the retry attempt number (`0, 1, 2...`), and multiplying by $2^k$ doubles your wait after each failure (`1s -> 2s -> 4s -> 8s`) until it hits a ceiling $t_{\max}$. Adding a tiny random delay $\epsilon_{\text{jitter}}$ keeps hundreds of users from retrying at the exact same millisecond.

## Try It Yourself: `.env` Validator & Backoff Calculator

Run this pure-Python script (locally or in a Colab cell) to practice safe API key masking, `.env` parsing, and free-tier exponential backoff scheduling without touching live network credentials.

**Secret Hygiene & Free-Tier Rate-Limit Planner**

```python
# 1. Simulated .env content and .gitignore entries
env_lines = [
    "# Local secrets file",
    "GEMINI_API_KEY=AIzaDemoKey19xQ2",
]
gitignore_entries = {".venv/", "__pycache__/", ".env"}

# Parse .env safely
config = {}
for line in env_lines:
    stripped = line.strip()
    if stripped and not stripped.startswith("#") and "=" in stripped:
        key, value = stripped.split("=", 1)
        config[key.strip()] = value.strip()

raw_key = config.get("GEMINI_API_KEY", "")
masked = f"{raw_key[:4]}****{raw_key[-4:]}" if len(raw_key) >= 8 else "INVALID"
valid_prefix = raw_key.startswith("AIza")
print(f"Loaded key: {masked} (valid_prefix={valid_prefix}, length={len(raw_key)})")
print(f"Gitignore protects .env: {'.env' in gitignore_entries}")

# 2. Free-tier RPM batch planner & exponential backoff schedule
total_requests = 45
rpm_limit = 15
print(f"Batch of {total_requests} requests @ {rpm_limit} RPM -> {total_requests / rpm_limit:.2f} minutes")

t0, t_max = 1.0, 10.0
backoff = [min(t_max, t0 * (2 ** k)) for k in range(5)]
print(f"Retry backoff schedule (t0={t0}s, max={t_max}s): {backoff}")
```

**Expected Output:**

```text
Loaded key: AIza****9xQ2 (valid_prefix=True, length=16)
Gitignore protects .env: True
Batch of 45 requests @ 15 RPM -> 3.00 minutes
Retry backoff schedule (t0=1.0s, max=10.0s): [1.0, 2.0, 4.0, 8.0, 10.0]
```
