Semantic search finds relevant passages; **Retrieval-Augmented Generation (RAG)** takes the next step by injecting those retrieved passages directly into an LLM's prompt so it can synthesize grounded, verifiable answers over your private knowledge base. Whether you are indexing internal engineering wikis or Neural Network lecture notes (`perceptron.md`, `own_framework.md`, `frameworks.md`), RAG eliminates stale training cutoffs and slashes hallucination rates. In this lesson, we'll build a complete RAG pipeline with **word-bounded chunking**, **`BallTree` / `ChromaDB` vector indexing**, and quantitative **Mean Average Precision (MAP)** evaluation.

## RAG Architecture & Vector Similarity Metrics

Every RAG system pairs a **Retriever** (embedding + vector index) with a **Generator** (LLM):
- **RAG-Sequence**: Uses the same top-$k$ retrieved passages to condition the entire generated answer.
- **RAG-Token**: Allows each generated token to attend to a different set of retrieved passages.

| Metric | Formula | Geometric Meaning |
| :--- | :--- | :--- |
| **Cosine Similarity** | $\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|_2 \|\mathbf{b}\|_2}$ | Angle between vectors (scale-invariant) |
| **Euclidean Distance ($L_2$)** | $\sqrt{\sum_{i=1}^d (a_i - b_i)^2}$ | Straight-line distance between endpoints |
| **Dot Product** | $\sum_{i=1}^d a_i b_i$ | Magnitude-weighted directional alignment |

## Word-Bounded Chunking & Vector Indexing

Chopping markdown files at an arbitrary character index cuts words in half and ruins embeddings. Instead, `split_text(text, max_length=400, min_length=300)` walks backward to the nearest whitespace boundary so every chunk lands cleanly between 300 and 400 characters without splitting words:

1. **Ingest & Explode**: Load `perceptron.md`, `own_framework.md`, and `frameworks.md` into a Pandas DataFrame and call `df.explode('chunks')`.
2. **Embed & Index**: Generate vector embeddings and index them with `NearestNeighbors(n_neighbors=5, algorithm='ball_tree')` or open-source **`ChromaDB`**.
3. **Retrieve & Generate**: Run `nbrs.kneighbors([query_vec])` for `"what is a perceptron?"`, pass the top-5 chunks into `gemini-2.5-flash`, and instruct the model to answer strictly from the retrieved context.

### Evaluating RAG Quality with Mean Average Precision (MAP)

Never ship a RAG pipeline on vibes alone. Measure retrieval and answer relevance across a golden query set $Q$ (*"What is a perceptron?"*, *"What is machine learning?"*, *"What is deep learning?"*, *"What is a neural network?"*) using **Mean Average Precision (MAP)**:

$$\text{MAP} = \frac{1}{|Q|} \sum_{q=1}^{|Q|} \text{AP}(q), \qquad \text{AP}(q) = \sum_{k=1}^{n} (R_k - R_{k-1}) P_k$$

def split_text(text, max_length=400, min_length=300):
    chunks, start = [], 0
    while start < len(text):

        chunks.append(text[start:end].strip())
        start = end + 1
