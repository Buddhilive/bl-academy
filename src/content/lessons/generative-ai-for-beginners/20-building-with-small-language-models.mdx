Not every task needs a 400-billion-parameter model running in a remote data center. **Small Language Models (SLMs)**—typically 1B to 14B parameters trained via knowledge distillation, pruning, quantization, and "textbook-quality" curated data—deliver fast, private, low-cost inference on a single Colab T4 GPU or even a laptop. In this lesson, we'll compare SLMs against LLMs across five dimensions and walk through four production SLM patterns: **Instruct SLMs**, **Vision SLM Video Keyframe Summarization**, **Sparse MoE SLMs**, and **ONNX Runtime for GenAI**.

---

## SLMs vs. LLMs: The 5-Dimension Comparison

| Dimension | Small Language Models (SLMs) | Large Language Models (LLMs) |
| :--- | :--- | :--- |
| **Size** | Typically 1B–14B parameters (e.g., 3.8B `Phi-3.5-mini`, 2B `Gemma-2`) | 70B to >1T parameters |
| **Comprehension** | High accuracy on focused domain, code, and extraction tasks | Broad generalist reasoning across obscure trivia |
| **Computing** | Single T4 GPU, laptop CPU/NPU, or offline edge device | Multi-GPU data center clusters |
| **Bias & Safety** | Trained on heavily filtered, textbook-grade synthetic/curated mixes | Broad internet corpora requiring heavier post-training |
| **Latency** | Sub-second Time-to-First-Token; zero network round-trip locally | Higher latency and per-token API cost |

---

## 3 Specialized SLM Variants & Edge Runtimes

1. **Instruct SLMs (`AutoModelForCausalLM`)**: Use structured chat tokens (`<|system|>...<|end|><|user|>...<|end|><|assistant|>`) with `transformers.pipeline("text-generation")`.
2. **Vision SLMs & OpenCV Video Keyframe Extraction**: Instead of feeding 1,800 redundant frames from a 60-second video, compute normalized HSV color histograms (`cv2.calcHist` + `cv2.compareHist`) and extract only frames where correlation drops below `0.9` (`<|image_1|>...<|image_N|>`).
3. **Sparse Mixture-of-Experts SLMs (`PhiMoESparseMoeBlock`)**: Pack 16 specialized `3.8B` experts (~42B total parameters) while a learned gate (`Linear(4096, 16)`) routes each token to only the **top-2 experts** ($6.6\text{B}$ active parameters per token).
4. **ONNX Runtime for GenAI (`onnxruntime-genai`)**: Executes an explicit token-by-token autoregressive loop (`generator.compute_logits()` $\rightarrow$ `generator.generate_next_token()`) across CPU, CUDA, and DirectML.

# 1. OpenCV-style histogram correlation for video keyframe extraction
def hist_corr(h1, h2):
    m1, m2 = sum(h1) / len(h1), sum(h2) / len(h2)
    num = sum((a - m1) * (b - m2) for a, b in zip(h1, h2))
    den = math.sqrt(sum((a - m1)**2 for a in h1) * sum((b - m2)**2 for b in h2))
    return num / den if den else 0.0

f1 = [0.80, 0.15, 0.05]
f2 = [0.78, 0.16, 0.06]
f3 = [0.10, 0.25, 0.65]

for idx, (a, b) in enumerate([(f1, f2), (f2, f3)], 1):
    c = hist_corr(a, b)
    keep = c < 0.9
    tag = "NEW KEYFRAME" if keep else "static scene"
    print(f"Frame {idx} -> Frame {idx+1} corr={c:.3f} (Keep={keep}: {tag})")

# 2. Top-2 Sparse MoE gating across 16 experts
logits = [0.1] * 16
logits[4] = 2.4
logits[11] = 2.1
exps = [math.exp(x) for x in logits]
probs = [e / sum(exps) for e in exps]
top2 = sorted(enumerate(probs), key=lambda x: x[1], reverse=True)[:2]
print("Sparse MoE (16 experts, top-2 active):")
print(f"  Active Experts: {[(idx, round(p, 3)) for idx, p in top2]}")
print(f"  Active Compute Ratio: 2/{len(logits)} experts ({2/len(logits)*100:.1f}%)")`}
