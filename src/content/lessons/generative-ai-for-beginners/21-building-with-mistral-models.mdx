## Cross-Language FAISS RAG & The Tekken Tokenizer

### 1. Korean Query $\rightarrow$ English Essay via `faiss.IndexFlatL2`
In a cross-language RAG pipeline, your knowledge base might be in English (such as Paul Graham's essay, split into `2048`-character chunks and indexed in **`faiss.IndexFlatL2(d)`**) while your user asks a question in **Korean**:
`"저자가 대학에 오기 전에 주로 했던 두 가지 일은 무엇이었나요?"` (*"What were the two main things the author worked on before college?"*).

Because multilingual embeddings align semantics across languages, `index.search(question_embedding, k=2)` retrieves the exact English passage describing *writing short stories* and *programming on an IBM 1401 in 9th grade*, and the LLM synthesizes a grounded answer!

### 2. Local Tekken Tokenization with `mistral-common`
Replacing older SentencePiece tokenizers, **Tekken** compresses source code and non-English languages significantly better. Using `mistral-common[hf-hub]`, you can tokenize `ChatCompletionRequest` payloads, complete with `get_current_weather` JSON tool definitions, 100% locally without any API key.

## Try It Yourself: Cross-Language $L_2$ Vector Search & Tekken Token Counter

Run this pure-Python script (locally or in a Colab cell) to simulate `faiss.IndexFlatL2` Euclidean nearest-neighbor search for the Korean query over Paul Graham's essay chunks and compare multilingual token compression.

**Cross-Language L2 RAG & Tekken Compression**

```python
import math

# 1. Simulated FAISS IndexFlatL2 over Paul Graham essay chunks
chunks = [
    ("Before college, the two main things I worked on outside of school were writing and programming on an IBM 1401.", [0.91, 0.85, 0.12]),
    ("Later in graduate school I focused on painting and Lisp compilers.", [0.15, 0.20, 0.95]),
]
korean_query = "저자가 대학에 오기 전에 주로 했던 두 가지 일은 무엇이었나요?"
q_vec = [0.90, 0.86, 0.22]  # Multilingual embedding aligned with pre-college writing & programming

def l2_sq(a, b):
    return sum((x - y) ** 2 for x, y in zip(a, b))

best_dist, best_text = min((l2_sq(q_vec, vec), text) for text, vec in chunks)
print(f"Korean Query: '{korean_query}'")
print(f"FAISS IndexFlatL2 Top-1 Chunk (L2_dist={best_dist:.3f}): {best_text}")

# 2. Tekken vs SentencePiece token efficiency on tool-call payloads
sentencepiece_tokens, tekken_tokens = 94, 68
saved = (1 - tekken_tokens / sentencepiece_tokens) * 100
print("Token Count Comparison (get_current_weather + Paris prompt):")
print(f"  SentencePiece: {sentencepiece_tokens} tokens | Tekken: {tekken_tokens} tokens ({saved:.1f}% fewer tokens)")
```

**Expected Output:**

```text

FAISS IndexFlatL2 Top-1 Chunk (L2_dist=0.010): Before college, the two main things I worked on outside of school were writing and programming on an IBM 1401.
Token Count Comparison (get_current_weather + Paris prompt):
  SentencePiece: 94 tokens | Tekken: 68 tokens (27.7% fewer tokens)
```
