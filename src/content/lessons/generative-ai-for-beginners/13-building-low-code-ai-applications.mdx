Not every AI application needs a custom React frontend and microservice backend. Often, the fastest way to ship internal tools—like a **Student Assignment Tracker** or an **Automated Invoice Processing Pipeline**—is a **low-code Python stack** combining declarative UIs (**Gradio**), lightweight relational tables (**SQLite**), and **Gemini 2.5 Flash** multimodal structured extraction. In this lesson, we'll build both workflows from scratch on Google Colab Free Tier.

---

## Core Building Blocks of Low-Code AI Apps

Low-code AI development replaces boilerplate HTML/REST plumbing with four composable primitives:

| Primitive | Open-Source Python Equivalent | Role in Our Workflows |
| :--- | :--- | :--- |
| **Relational Data Table** | `sqlite3` / `Pandas` DataFrame | Stores `StudentAssignments` and `InvoiceInfo` rows persistently |
| **Declarative Web UI** | `Gradio` (`gr.Blocks`, `gr.Dataframe`, `gr.Button`) | Auto-generates interactive forms, file uploaders, and shareable links |
| **Prebuilt AI Capabilities** | `google-genai` (`gemini-2.5-flash` + Pydantic) | Handles OCR, Invoice Extraction, Sentiment Analysis, Key Phrases, and Language Detection |
| **Event-Driven Automation** | Python callback triggers | Upload invoice $\rightarrow$ extract JSON $\rightarrow$ insert SQLite row $\rightarrow$ draft supplier email |

---

## Workflow 1: Student Assignment Tracker & AI Assistant

Teachers and bootcamps need a single dashboard to track assignment submissions (`Assignment_ID`, `Title`, `Student_Name`, `Student_Email`, `Due_Date`, `Status`, `Score`). With **Gradio**, a 30-line Python script renders an interactive submission table, lets an instructor filter pending assignments, and triggers `gemini-2.5-flash` to draft constructive rubric feedback and a personalized student notification email.

---

## Workflow 2: Automated Invoice Extraction Pipeline

Manual invoice entry is slow and error-prone. By pairing **Gemini 2.5 Flash** multimodal structured outputs (`response_schema=InvoiceRecord`) with `sqlite3`, an automated workflow runs in three steps:

1. **Extract**: Parse `ID`, `Amount`, `Date`, `Vendor_Name`, `Status`, and `Supplier_Email` from an uploaded invoice PDF or image.
2. **Enrich**: Run prebuilt NLP checks (Language Detection, Key Phrase Extraction, Sentiment Analysis on vendor notes).
3. **Store & Notify**: Insert the validated record into the `InvoiceInfo` table and draft an automated confirmation email to `Supplier_Email`.
