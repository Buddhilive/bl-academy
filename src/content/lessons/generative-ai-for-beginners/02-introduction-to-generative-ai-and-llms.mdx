When you type a question into a modern AI assistant and watch a coherent paragraph stream onto your screen word by word, it can feel like the model is "thinking" like a human writer. Under the hood, a Large Language Model (LLM) is doing something far more mathematical: it is predicting one subword **token** at a time based on conditional probability distributions learned from massive text corpora. In this lesson, we'll trace how Generative AI evolved, unpack tokenization and Transformer self-attention, and see how **temperature** shifts an LLM from deterministic precision to creative exploration.

---

## Where Generative AI Fits in the AI Landscape

Generative AI is not a separate universe from Machine Learning—it is a specialized branch nested inside **Artificial Intelligence $\supset$ Machine Learning $\supset$ Deep Learning $\supset$ Generative AI**.

Over the past six decades, language AI evolved through four distinct eras:
1. **1960s Rule-Based Chatbots**: Hardcoded keyword and pattern-matching scripts (like ELIZA) that broke the moment phrasing changed.
2. **1990s Statistical ML**: Classifiers predicting spam or sentiment using bag-of-words frequencies.
3. **2000s–2010s Recurrent Neural Networks (RNNs)**: Sequential models processing text one word at a time, which struggled to remember context across long paragraphs.
4. **2017+ Transformer Architecture**: Replaced sequential recurrence with **self-attention**, enabling models to weigh relationships between *all* tokens in a prompt simultaneously.

## How Large Language Models Generate Text

Every LLM text generation request follows a clean, repeatable pipeline:

| Stage | What Happens | Key Concept |
| :--- | :--- | :--- |
| **1. Tokenization** | Input text is split into subword units and mapped to integer IDs | Common words stay whole (`"cat"`); rare words split (`"token" + "ization"`) |
| **2. Self-Attention** | Transformer layers compute contextual weights across all input tokens | Resolves pronouns and long-range dependencies across the context window |
| **3. Next-Token Prediction** | Model outputs logits $z_i$ over vocabulary $V$ for the next token | Predicts 1 token $t_{n+1} \sim P(w \mid t_1, \dots, t_n)$ |
| **4. Expanding Window** | Predicted token $t_{n+1}$ is appended to the prompt and fed back in | Autoregressive loop repeats until `<EOS>` or token limit |

### Autoregressive Probability & Softmax Temperature

Formally, an autoregressive LLM factors the joint probability of a sequence $w_{1:T}$ as a chain of conditional next-token probabilities:

$$P(w_{1:T}) = \prod_{t=1}^{T} P(w_t \mid w_1, w_2, \dots, w_{t-1})$$

Before sampling the next token, raw model scores (**logits** $z_i$) are converted into probabilities using **temperature-scaled softmax**:

$$P(w_i \mid w_{<t}) = \frac{\exp(z_i / T)}{\sum_{j=1}^{|V|} \exp(z_j / T)}$$

- **Low Temperature ($T \to 0$)**: Sharpens the distribution toward the highest-scoring token, making responses focused, repeatable, and nearly deterministic.
- **High Temperature ($T \ge 1.0$)**: Flattens the distribution, boosting lower-probability tokens for creative brainstorming—at the cost of higher **fabrication (hallucination)** risk.

# 1. Simple subword vocabulary & greedy longest-match tokenizer
vocab = {"gen": 10, "er": 11, "ative": 12, "ai": 13, "rocks": 14, "helps": 15}
def tokenize(text):
    tokens = []
    for word in text.lower().split():
        i = 0
        while i < len(word):
            matched = None
            for end in range(len(word), i, -1):
                if word[i:end] in vocab:
                    matched = word[i:end]
                    break
            tokens.append(matched if matched else word[i])
            i += len(matched) if matched else 1
    return tokens

sample = "Generative AI rocks"
toks = tokenize(sample)
ids = [vocab[t] for t in toks]
print(f"Tokens: {toks} -> IDs: {ids}")

# 2. Temperature-scaled softmax over candidate next-token logits
candidates = [("rocks", 4.0), ("helps", 3.2), ("sleeps", 2.0)]
def softmax_temp(items, temp):
    scaled = [math.exp(logit / temp) for _, logit in items]
    total = sum(scaled)
    return [(word, round(p / total, 3)) for (word, _), p in zip(items, scaled)]

print(f"T=0.2 (Focused): {softmax_temp(candidates, 0.2)}")
print(f"T=1.5 (Creative): {softmax_temp(candidates, 1.5)}")

# 3. Autoregressive expanding window step
prompt = "Generative AI"
next_tok = softmax_temp(candidates, 0.2)[0][0]
print(f"Autoregressive Step 1: '{prompt}' + ' {next_tok}'")`}
