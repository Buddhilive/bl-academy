## Native `<|python_tag|>` Function Calling & Multimodal Vision

Llama 3.1+ models are fine-tuned on special header tokens (`<|begin_of_text|>`, `<|start_header_id|>`, `<|eot_id|>`) to invoke built-in tools (**Brave Search** for live web queries and **Wolfram Alpha** for symbolic math) as well as custom Python tools:

```text
<|begin_of_text|><|start_header_id|>system<|end_header_id|>
Environment: ipython
Tools: brave_search, wolfram_alpha
Cutting Knowledge Date: December 2023
Today Date: 23 July 2024
You are a helpful assistant<|eot_id|>
```

When asked `"What is the weather in Stockholm?"`, the model emits:
`<|python_tag|>brave_search.call(query="Stockholm weather")`

For **Multimodal Vision**, images (`sample.jpg`) are encoded as base64 data URLs or PIL Images alongside text prompts (`"What's in this image?"`) so a single model can inspect diagrams, receipts, or photographs.

# 1. Compile Llama native tool-calling system prompt
tools = ["brave_search", "wolfram_alpha"]
header = (
    "<|begin_of_text|><|start_header_id|>system<|end_header_id|>\\n"
    f"Environment: ipython\\nTools: {', '.join(tools)}\\n"
    "You are a helpful assistant<|eot_id|>"

print(f"Compiled Header Tools: {', '.join(tools)}")

# 2. Parse <|python_tag|> tool call emitted by Llama
emitted = "<|python_tag|>brave_search.call(query='Stockholm weather')"
print(f"Model Emitted: {emitted}")

tool_name, query_val = match.group(1), match.group(2)
print(f"Parsed Tool: {tool_name} | Args: {{'query': '{query_val}'}}")

# 3. Execute tool & format ipython observation turn
mock_weather = {"Stockholm weather": "Stockholm: 14C, Partly Cloudy"}
