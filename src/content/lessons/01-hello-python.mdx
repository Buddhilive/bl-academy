## Python Syntax

Python syntax can be executed directly by writing code statements in an interactive environment or script file. Unlike many other programming languages that use curly brackets `{}` or semicolons `;` to complete commands and define blocks, Python was designed for readability and uses new lines to complete a command and whitespace indentation to define scope.

### Python Indentation

Indentation refers to the spaces at the beginning of a code line. Where in other programming languages the indentation in code is for readability only, the indentation in Python is very important. Python uses indentation to indicate a block of code:

```python
if 5 > 2:
    print("Five is greater than two!")
```

### Python Variables & Values

In Python, variables are created when you assign a value to them. Variables do not need to be declared with any particular type, and can even change type after they have been set:

```python
x = 5         # x is of type int
y = "Buddhi"  # y is of type str
```

## Example: Calculate Euclidean Norm

Below is a complete, copyable Python snippet demonstrating variable definition, standard arithmetic operations, and importing the built-in `math` module to calculate Euclidean distance:

```python
# Calculate Euclidean Norm
import math

x = 3.0
y = 4.0
magnitude = math.sqrt(x**2 + y**2)

print(f"Coordinates: ({x}, {y})")
print(f"Euclidean Norm: {magnitude}")
```

## Arithmetic Operators Reference

Python provides standard arithmetic operators conforming strictly to IEEE 754 precision standards:

| Operator | Name | Description | Example |
| :--- | :--- | :--- | :--- |
| `+` | Addition | Adds two values together | `x + y` |
| `-` | Subtraction | Subtracts right operand from left | `x - y` |
| `*` | Multiplication | Multiplies two values | `x * y` |
| `/` | Float Division | Divides left by right, returning float | `x / y` |
| `//` | Floor Division | Divides and returns integer floor | `x // y` |
| `%` | Modulus | Returns division remainder | `x % y` |
| `**` | Exponentiation | Left operand raised to power of right | `x ** 2` |

## Quick Self-Check

What will be the output of `print(10 // 3)` in Python?

- A) `3.3333`
- B) `3`
- C) `1`
- D) `TypeError`

*(Answer: **B** — The `//` operator performs floor division, discarding any fractional remainder.)*
