## The 4-Tier MCP Testing Pyramid

A reliable MCP server test suite covers four distinct layers:

| Testing Tier | What It Verifies | Tooling |
| :--- | :--- | :--- |
| **1. Unit Tests** | Pure tool logic, math guards, Pydantic input validation | `pytest` directly on Python functions |
| **2. In-Memory Integration** | Full JSON-RPC serialization between client and server | `create_connected_server_and_client_session` |
| **3. Protocol Conformance** | `tools/list` schemas, `readOnlyHint`/`destructiveHint`, `-32602` errors | Automated conformance assertions (`SEP-2484`) |
| **4. Interactive Inspection** | Visual tool/resource invocation, raw JSON-RPC wire trace | `npx @modelcontextprotocol/inspector` |

### Debugging with MCP Inspector

The official **MCP Inspector** (`@modelcontextprotocol/inspector`) launches a local web UI (`http://127.0.0.1:6274`) backed by an MCP proxy (`port 6277`), or runs headlessly in CLI mode for CI pipelines:

```bash
# Launch visual Inspector UI against a Python server
npx @modelcontextprotocol/inspector python server.py

# Headless CLI mode to list tools
npx @modelcontextprotocol/inspector --cli python server.py --method tools/list
```

In Google Colab or automated Python CI, you can replicate the exact same Inspector workflow using `create_connected_server_and_client_session(server._mcp_server)` from `mcp.shared.memory` so tests run in milliseconds with zero port binding.

## Try It Yourself: Automated MCP Conformance & Inspector Runner

Run this pure-Python conformance suite to audit an MCP server across 5 protocol assertions: schema completeness, Tool Annotations, happy-path execution, unknown-tool `-32601` error handling, and missing-resource `-32602` compliance.

**MCP Conformance & Inspector Test Runner**

```python
def run_conformance_suite(server_tools: dict, server_resources: dict):
    passed = 0
    total = 5

    # 1. Schema check
    schemas_ok = all("inputSchema" in t and "description" in t for t in server_tools.values())
    assert schemas_ok
    print(f"[PASS] tools/list schema check ({len(server_tools)} tools valid)")
    passed += 1

    # 2. Annotations check
    ann_ok = all("annotations" in t for t in server_tools.values())
    assert ann_ok
    print("[PASS] Tool annotations present on all tools")
    passed += 1

    # 3. Happy path call
    res = server_tools["ping"]["fn"]()
    assert res == "pong"
    print(f"[PASS] tools/call 'ping' -> '{res}'")
    passed += 1

    # 4. Unknown tool -> -32601
    err_tool = -32601 if "ghost_tool" not in server_tools else 0
    assert err_tool == -32601
    print(f"[PASS] Unknown tool returned {err_tool}")
    passed += 1

    # 5. Missing resource -> -32602
    err_res = -32602 if "file://missing" not in server_resources else 0
    assert err_res == -32602
    print(f"[PASS] Missing resource returned {err_res}")
    passed += 1

    print(f"Conformance Summary: {passed}/{total} checks passed")

TOOLS = {
    "ping": {"description": "Health check", "inputSchema": {"type": "object"}, "annotations": {"readOnlyHint": True}, "fn": lambda: "pong"},
    "sum_two": {"description": "Add two ints", "inputSchema": {"type": "object"}, "annotations": {"readOnlyHint": True}, "fn": lambda a, b: a + b},
}
RESOURCES = {"docs://readme": "MCP Server Docs"}
run_conformance_suite(TOOLS, RESOURCES)
```

**Expected Output:**

```text
[PASS] tools/list schema check (2 tools valid)
[PASS] Tool annotations present on all tools
[PASS] tools/call 'ping' -> 'pong'
[PASS] Unknown tool returned -32601
[PASS] Missing resource returned -32602
Conformance Summary: 5/5 checks passed
```
