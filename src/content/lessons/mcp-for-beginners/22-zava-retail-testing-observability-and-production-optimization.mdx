## Try It Yourself: Zava Retail Security Audit & OpenTelemetry Profiler

Run this pure-Python sandbox to execute a 4-check RLS/SQLi security audit, propagate a W3C `traceparent` span, and calculate $P_{50}$/$P_{95}$ query latencies and embedding cache hit ratio.

**Zava Retail Security Audit & P95 Observability**

```python
# 1. Automated RLS & SQLi security checks
checks = [
    ("seattle_cannot_read_redmond", True),
    ("redmond_cannot_read_seattle", True),
    ("drop_table_blocked", True),
    ("stacked_semicolon_blocked", True),
]
passed = sum(1 for _, ok in checks if ok)
print(f"[Audit] {passed}/{len(checks)} RLS & SQLi checks passed")

# 2. W3C traceparent propagation (SEP-414)
traceparent = "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"
print(f"[OTel Span] traceparent={traceparent} | span=zava.hybrid_search")

# 3. Latency percentiles (P50, P95) & Cache Hit Ratio
latencies_ms = sorted([8.0, 10.0, 11.0, 12.0, 14.0, 15.0, 18.0, 21.0, 29.0, 42.0])
p50 = latencies_ms[int(0.50 * (len(latencies_ms) - 1))]
p95 = latencies_ms[int(0.95 * (len(latencies_ms) - 1))]
print(f"[Latency] P50={p50:.1f}ms, P95={p95:.1f}ms")

hits, misses = 8, 2
hit_ratio = hits / (hits + misses) * 100
print(f"[Cache] hits={hits}, misses={misses} -> hit_ratio={hit_ratio:.1f}%")
```

**Expected Output:**

```text
[Audit] 4/4 RLS & SQLi checks passed
[OTel Span] traceparent=00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01 | span=zava.hybrid_search
[Latency] P50=14.0ms, P95=42.0ms
[Cache] hits=8, misses=2 -> hit_ratio=80.0%
```
