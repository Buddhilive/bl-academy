In 1957, Frank Rosenblatt built the **Mark I Perceptron**, a physical hardware machine wired with a $20 \times 20$ grid of photocells (400 inputs) and motorized potentiometers that adjusted weights during training. It was one of the earliest working artificial neural networks, and it laid the mathematical foundation for everything we call deep learning today.

At its core, a perceptron is a **linear binary classifier**: it takes a list of numbers describing an input (features), multiplies each number by an importance **weight**, adds them up, and decides whether the input belongs to the "Yes" class ($+1$) or the "No" class ($-1$).

Think of it like deciding whether to go for a walk based on two clues: **temperature** and **sunshine**. If you care a lot about sunshine (high positive weight) and slightly less about temperature, you mentally combine those clues into a single score. If the score crosses your personal threshold, you go ($+1$); otherwise you stay inside ($-1$).

---

## The Mathematical Model

In math notation, we write the list of $N$ input features as a vector $\mathbf{x} = [x_1, x_2, \dots, x_N]^{\top}$, each feature's importance as a weight vector $\mathbf{w} = [w_1, w_2, \dots, w_N]^{\top}$, and your baseline threshold offset as a single number called the **bias** $b$. The perceptron computes:

$$y(\mathbf{x}) = f(\mathbf{w}^{\top}\mathbf{x} + b)$$

Let's read each piece of that formula in plain English:
- $\mathbf{w}^{\top}\mathbf{x}$ is the **dot product**, you simply multiply each input feature $x_i$ by its matching weight $w_i$ and add all the results together ($w_1 x_1 + w_2 x_2 + \dots + w_N x_N$).
- $+ b$ shifts the score up or down, acting like a baseline preference before any input features are even multiplied.
- To keep the code and math tidy, we often append a constant `1` to the end of $\mathbf{x}$ and fold $b$ into $\mathbf{w}$ (a trick called **homogeneous coordinates**), letting us write the whole weighted sum simply as $\mathbf{w}^{\top}\mathbf{x}$.
- $f(z)$ is the **step activation function**: it checks the raw score $z$ and snaps it to either $+1$ or $-1$:

$$f(z) = \begin{cases} +1 & \text{if } z \ge 0 \\ -1 & \text{if } z < 0 \end{cases}$$

Geometrically, the equation $\mathbf{w}^{\top}\mathbf{x} + b = 0$ defines a **hyperplane**, which is just a straight line on a 2D graph, or a flat sheet in 3D, that slices the data into two regions: $+1$ on one side and $-1$ on the other.

## The Perceptron Learning Rule

How does the perceptron find the right weights $\mathbf{w}$ automatically? By learning from its mistakes. Whenever it guesses wrong on a training example, we nudge the weights slightly in the direction that would have produced the right answer.

Formally, we measure total error using the **perceptron criterion** summed over all currently misclassified samples ($\mathcal{M}$):

$$E(\mathbf{w}) = -\sum_{i \in \mathcal{M}} \mathbf{w}^{\top}\mathbf{x}_i t_i$$

Here, $t_i \in \{-1, +1\}$ is the true label for sample $i$. Notice why the minus sign makes sense: whenever a point is misclassified, the model's raw score $\mathbf{w}^{\top}\mathbf{x}_i$ and the true label $t_i$ have *opposite* signs, so their product is negative, and the minus sign turns that into a positive penalty! Applying **gradient descent** (taking small steps downhill to shrink the error) gives the **Perceptron Update Rule** whenever a prediction $\hat{y}_i \neq t_i$:

$$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} + \eta \cdot t_i \mathbf{x}_i$$

In plain English: take the current weights $\mathbf{w}^{(t)}$, and add a small fraction $\eta$ (the learning rate) of the input $\mathbf{x}_i$ if the true label is $+1$, or subtract it if the true label is $-1$. If the prediction was already correct, we don't change the weights at all.

| Parameter / Symbol | Meaning | Role in Training |
| :--- | :--- | :--- |
| $\mathbf{x}_i$ | Input feature vector (with bias $1$ appended) | Represents one training sample in $\mathbb{R}^{N+1}$. |
| $\mathbf{w}$ | Learned weight vector | Defines the orientation and offset of the separating hyperplane. |
| $t_i \in \{-1, +1\}$ | Ground-truth class label | Pushes weights toward $\mathbf{x}_i$ when $t_i=+1$ and away when $t_i=-1$. |
| $\eta$ (`eta`) | Learning rate (e.g., `0.1` or `1.0`) | Controls step size during each misclassification correction. |

### Scaling to Multi-Class Classification

A single perceptron only separates two classes. To classify $K$ classes (such as the 10 handwritten digits `0`–`9` in MNIST), we train $K$ independent **One-vs-Rest** perceptrons, one per digit, and pick the class whose neuron produces the highest raw score $\mathbf{w}_k^{\top}\mathbf{x}$.

## Hands-On: Training a Binary Perceptron in Python

Let's train a perceptron from scratch on two linearly separable 2D clusters in pure Python (run it in Colab or locally). Watch how the weights start at `[0.0, 0.0, 0.0]` and converge to 100% accuracy in just a few epochs.

**Perceptron Training Loop**

```python
# Dataset: (x1, x2, bias=1.0) -> label (+1 or -1)
dataset = [
    ([2.0, 3.0, 1.0], +1),
    ([3.0, 2.0, 1.0], +1),
    ([0.5, 0.5, 1.0], -1),
    ([1.0, 0.2, 1.0], -1),
]

def dot(a: list[float], b: list[float]) -> float:
    return sum(x * y for x, y in zip(a, b))

def predict(x: list[float], w: list[float]) -> int:
    return 1 if dot(x, w) >= 0.0 else -1

weights = [0.0, 0.0, 0.0]
eta = 0.1

for epoch in range(1, 20):
    errors = 0
    for x, target in dataset:
        y_hat = predict(x, weights)
        if y_hat != target:
            weights = [round(w_j + eta * target * x_j, 4) for w_j, x_j in zip(weights, x)]
            errors += 1
    print(f"Epoch {epoch}: errors={errors}, weights={weights}")
    if errors == 0:
        print(f"Converged at epoch {epoch}!")
        break

for pt, expected in [([3.0, 3.0, 1.0], "+1"), ([0.2, 0.4, 1.0], "-1")]:
    pred = "+1" if predict(pt, weights) == 1 else "-1"
    print(f"Test ({pt[0]}, {pt[1]}) -> {pred} (expected {expected})")
```

**Expected Output:**

```text
Epoch 1: errors=1, weights=[-0.05, -0.05, -0.1]
Epoch 2: errors=3, weights=[0.0, 0.18, -0.2]
Epoch 3: errors=0, weights=[0.0, 0.18, -0.2]
Converged at epoch 3!
Test (3.0, 3.0) -> +1 (expected +1)
Test (0.2, 0.4) -> -1 (expected -1)
```
