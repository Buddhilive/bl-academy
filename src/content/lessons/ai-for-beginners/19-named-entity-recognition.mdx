Document classification assigns one label to an entire sentence. **Named Entity Recognition (NER)** goes down to the individual word level: it scans unstructured text and tags specific real-world entities such as people (`PER`), organizations (`ORG`), locations (`LOC`), dates, or medical compounds (`CHEM`, `DIS`).

Whenever a voice assistant extracts *"Seattle"* and *"tomorrow"* from *"What's the weather in Seattle tomorrow?"*, or a biomedical pipeline mines drug–disease pairs from research papers, NER is doing the heavy lifting.

---

## NER as Token Classification & BIO Tagging

Because a single entity can span multiple consecutive words—and two different entities can sit right next to each other—we need a tagging scheme that marks exact span boundaries. The industry standard is **BIO (Beginning–Inside–Outside)** tagging:

- **`B-<TYPE>`**: First token of an entity of type `<TYPE>` (e.g., `B-DIS` or `B-CHEM`).
- **`I-<TYPE>`**: Continuation token inside the same entity span (`I-DIS`).
- **`O`**: Outside any named entity.

Consider this medical paper title: *"Tricuspid valve regurgitation and lithium carbonate toxicity in a newborn infant."*

| Token | BIO Tag | Entity Span |
| :--- | :--- | :--- |
| `Tricuspid` | `B-DIS` | Disease #1 starts |
| `valve` | `I-DIS` | Disease #1 continues |
| `regurgitation` | `I-DIS` | Disease #1 ends |
| `and` | `O` | Non-entity |
| `lithium` | `B-CHEM` | Chemical starts |
| `carbonate` | `I-CHEM` | Chemical ends |
| `toxicity` | `B-DIS` | Disease #2 starts (separate from `CHEM`) |

Architecturally, NER is a **Many-to-Many** token classification task: every token $t$ passes through a Bidirectional LSTM or a Transformer Encoder (such as HuggingFace `AutoModelForTokenClassification`) followed by a linear head predicting its BIO tag ID. When working with subword tokenizers like BERT's WordPiece, a single long word such as `"regurgitation"` may split into `["reg", "##urg", "##itation"]`—so standard NER pipelines align labels only to the first subword piece and mask continuation subwords with `-100` in the loss function. This clean alignment lets pre-trained Transformers extract entities accurately across news, legal, and clinical domains.

## Hands-On: BIO Span Extractor & Entity-Level $F_1$ Scorer

In NER, token accuracy can look misleadingly high because most tokens are `O`. Real NER benchmarks score **exact entity spans** using Precision, Recall, and $F_1$. Let's build a pure-Python BIO span decoder and evaluator.

**BIO Tag Decoder & Entity F1 Evaluator**

```python
tokens = ["Tricuspid", "valve", "regurgitation", "and", "lithium", "carbonate", "toxicity"]
gold_tags = ["B-DIS", "I-DIS", "I-DIS", "O", "B-CHEM", "I-CHEM", "B-DIS"]
pred_tags = ["B-DIS", "I-DIS", "I-DIS", "O", "B-CHEM", "O", "B-DIS"]

def extract_spans(toks: list[str], tags: list[str]) -> list[tuple[str, str]]:
    spans = []
    cur_type, cur_words = None, []
    for tok, tag in zip(toks, tags):
        if tag.startswith("B-"):
            if cur_type:
                spans.append((cur_type, " ".join(cur_words)))
            cur_type = tag[2:]
            cur_words = [tok]
        elif tag.startswith("I-") and cur_type == tag[2:]:
            cur_words.append(tok)
        else:
            if cur_type:
                spans.append((cur_type, " ".join(cur_words)))
                cur_type, cur_words = None, []
    if cur_type:
        spans.append((cur_type, " ".join(cur_words)))
    return spans

g_spans = extract_spans(tokens, gold_tags)
p_spans = extract_spans(tokens, pred_tags)
tp = len(set(g_spans) & set(p_spans))
prec = tp / len(p_spans)
rec = tp / len(g_spans)
f1 = (2 * prec * rec) / (prec + rec)

print(f"Gold Entities:      {g_spans}")
print(f"Predicted Entities: {p_spans}")
print(f"Exact Span Match -> Precision: {prec:.2f} | Recall: {rec:.2f} | F1: {f1:.2f}")
```

**Expected Output:**

```text
Gold Entities:      [('DIS', 'Tricuspid valve regurgitation'), ('CHEM', 'lithium carbonate'), ('DIS', 'toxicity')]
Predicted Entities: [('DIS', 'Tricuspid valve regurgitation'), ('CHEM', 'lithium'), ('DIS', 'toxicity')]
Exact Span Match -> Precision: 0.67 | Recall: 0.67 | F1: 0.67
```
