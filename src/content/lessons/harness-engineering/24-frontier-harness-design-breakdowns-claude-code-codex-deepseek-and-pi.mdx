## Four Distinct Philosophies

1. **Claude Code ("Addition / Complete Runtime")**: Layers `CLAUDE.md` across four scopes (organization, user, project, local) plus subdirectory on-demand loading and 200-line/25KB auto-memory. Uses a **5-layer compaction pipeline** (lossless pruning → structured distillation → lossy LLM summary with circuit breakers), append-only `history.jsonl`, four extensions (Skills, MCP, Hooks, sidechain Subagents), and explicit permission modes (`Manual`, `Plan`, `acceptEdits`, `Auto`, `dontAsk`, `bypassPermissions`).
2. **OpenAI Codex ("Subtraction / Conventions & Worktrees")**: Monolithic Rust CLI treating `AGENTS.md` as a ~100-line **directory page** (*"give the map, not the manual"*), paired with **Write–Select–Compress–Isolate** context engineering, incremental environment deltas (`build_environment_update_item`), per-task **git worktree** isolation + local observability stack, and `.codex/agents/*.toml` (`spawn_agent` / `wait_agent`).
3. **DeepSeek Harness (`dsh`, "Harness as Model-Independent OS")**: Built on a Cordis plugin core where *everything is a plugin—including the agent loop itself*. Standardizes **Capability Seams** (`Service Definition → Service Provider → Consumer`) across Local/E2B/Remote FS, exposes a 12-stage Turn Flow **Event Pipeline**, and enforces the invariant **"Model-visible means logged"** in an append-only Session Event Log.
4. **Pi ("Minimal Core + Programmable Extensions")**: Ships a minimal `SYSTEM.md` + 3-level `AGENTS.md` and four customizable layers (TypeScript Extensions, Agent Skills, `/name` Prompt Templates, TUI Themes). Stores sessions as **Session Trees** (`/tree` branching & HTML/gist export) and makes compaction itself a pluggable extension (~20,000-token retention split point).
